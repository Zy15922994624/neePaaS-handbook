# 03-表单数据增删改查操作说明

> 整理日期：2026-05-17  
> 适用范围：neePaaS / 闪用前端插件 / 闪搭前端插件 / 表单数据 API  
> 目标：整理日常开发中查询、创建、更新、删除表单数据的常用写法、查询条件和常见坑。

---

## 1. 这篇解决什么问题

日常开发里，经常需要在插件中操作表单数据：

- 查询某个表单的所有数据
- 按条件查询数据
- 只查询部分字段
- 查询某条数据详情
- 创建一条或多条数据
- 更新一条或多条数据
- 删除一条或多条数据
- 获取表格选中行并批量处理
- 使用指定 ID 创建数据
- 前端调用后端接口分页查询

核心入口有两类：

```javascript
// 通用模型接口
invokeModelApi(modelId, action, id, data, query)
```

以及更直观的封装函数：

```javascript
getTableData(modelId, dataId)
getTableList(modelId, queryString)
createTableData(modelId, createData)
updateTableData(modelId, updateData)
deleteTableData(modelId, dataId)
```

本篇优先整理前端插件写法；中台 `crmodel` 会放在后面作为补充。

---

## 2. 前置要求：配置程序标识

使用 `getModel('xxx')` 前，必须先在表单和字段上配置好程序标识。

如果没有配置，常见问题是：

- `getModel('student')` 返回空或字段不完整。
- 拿不到 `modelId`。
- 拿不到字段 ID。
- 查询条件拼不出来。

推荐做法：

```javascript
const studentModel = getModel('student')
console.log('studentModel:', studentModel)
```

一个可用的模型对象通常包含：

```javascript
{
  modelId: 'ncmod_xxx',
  name: 'ncfld_xxx',
  gender: 'ncfld_xxx',
  age: 'ncfld_xxx'
}
```

其中：

- `modelId` 是表单 ID。
- `studentModel.name`、`studentModel.gender` 是字段 ID。
- 后续查询、创建、更新都建议使用这些字段 ID。

## 3. 两套 API 怎么选

### 3.1 推荐优先级

简单操作优先用封装函数：

```javascript
getTableData()
getTableList()
createTableData()
updateTableData()
deleteTableData()
```

需要明确指定动作或兼容旧示例时，用：

```javascript
invokeModelApi()
```

不推荐继续使用：

```javascript
invokeTableApi()
```

原文档说明：`invokeTableApi` 已经不推荐，除非有特殊场景需要获取 `total_count`。

### 3.2 `invokeModelApi` 参数

```javascript
invokeModelApi(modelId, action, id, data, query)
```

参数含义：

- `modelId`：表单 ID。
- `action`：操作类型，例如 `getList`、`getItem`、`create`、`update`、`delete`。
- `id`：数据 ID，部分动作需要。
- `data`：创建或更新的数据对象。
- `query`：查询字符串。

不需要的参数通常用 `0` 占位。

## 4. 查询数据

### 4.1 查询全部数据

```javascript
async function main() {
  const studentModel = getModel('student')

  const list = await getTableList(studentModel.modelId)

  console.log('学生列表:', list)
}

main()
```

或：

```javascript
async function main() {
  const studentModel = getModel('student')

  const list = await invokeModelApi(studentModel.modelId, 'getList')

  console.log('学生列表:', list)
}

main()
```

### 4.2 按字段等于查询

```javascript
async function main() {
  const studentModel = getModel('student')
  const query = '?' + studentModel.gender + '=男'

  const list = await getTableList(studentModel.modelId, query)

  console.log('男生列表:', list)
}

main()
```

### 4.3 多条件查询：并且关系

多个条件用 `&` 连接，表示并且。

```javascript
async function main() {
  const studentModel = getModel('student')

  const query =
    '?' +
    studentModel.gender + '=男' +
    '&' +
    studentModel.age + '__gte=18'

  const list = await getTableList(studentModel.modelId, query)

  console.log('查询结果:', list)
}

main()
```

### 4.4 多条件查询：或者关系

多个条件用 `|` 连接，表示或者。

```javascript
async function main() {
  const studentModel = getModel('student')

  const query =
    '?' +
    studentModel.gender + '=男' +
    '|' +
    studentModel.age + '__gte=18'

  const list = await getTableList(studentModel.modelId, query)

  console.log('查询结果:', list)
}

main()
```

注意：原文档说明 `&` 优先级高于 `|`。

### 4.5 查询单条数据

```javascript
async function main() {
  const studentModel = getModel('student')
  const dataId = '替换为实际数据ID'

  const data = await getTableData(studentModel.modelId, dataId)

  console.log('学生详情:', data)
}

main()
```

或：

```javascript
const data = await invokeModelApi(studentModel.modelId, 'getItem', dataId, 0, 0)
```

## 5. 常用查询操作符

查询参数格式：

```text
?字段ID__操作符=值
```

等于可以省略操作符：

```text
?字段ID=值
```

常用操作符：

- `exact`：等于
- `exclude` / `not`：不等于
- `isnull`：是否为空
- `gt`：大于
- `gte`：大于等于
- `lt`：小于
- `lte`：小于等于
- `range`：范围内
- `notrange`：范围外
- `in`：在指定值集合中
- `notin`：不在指定值集合中
- `like`：模糊匹配
- `ilike`：模糊匹配，不区分大小写
- `contains`：包含
- `icontains`：包含，不区分大小写
- `startswith`：以指定内容开头
- `endswith`：以指定内容结尾

### 5.1 包含查询

```javascript
const query = '?' + studentModel.name + '__contains=张'
const list = await getTableList(studentModel.modelId, query)
```

### 5.2 大于查询

```javascript
const query = '?' + studentModel.age + '__gt=18'
const list = await getTableList(studentModel.modelId, query)
```

### 5.3 范围查询

```javascript
const query = '?' + studentModel.createDate + '__range=2026-01-01,2026-01-31'
const list = await getTableList(studentModel.modelId, query)
```

### 5.4 多值查询

```javascript
const query = '?' + studentModel.status + '__in=待处理,处理中,已完成'
const list = await getTableList(studentModel.modelId, query)
```

### 5.5 空值查询

```javascript
const query = '?' + studentModel.remark + '__isnull=True'
const list = await getTableList(studentModel.modelId, query)
```

## 6. 分页、排序和搜索

### 6.1 分页查询

```javascript
const query = '?page=1&page_size=20'
const list = await getTableList(studentModel.modelId, query)
```

### 6.2 排序

正序：

```javascript
const query = '?ordering=createtime'
```

倒序：

```javascript
const query = '?ordering=-createtime'
```

多字段排序：

```javascript
const query = '?ordering=-createtime,' + studentModel.name
```

### 6.3 搜索

`search` 会按表单标题字段或列表配置里的可搜索字段查询。

```javascript
const query = '?search=张三'
const list = await getTableList(studentModel.modelId, query)
```

### 6.4 分页 + 条件 + 排序

```javascript
const query =
  '?page=1' +
  '&page_size=20' +
  '&ordering=-createtime' +
  '&' + studentModel.status + '=待处理'

const list = await getTableList(studentModel.modelId, query)
```

## 7. 只查询部分字段

当表单字段很多、数据量大时，可以使用 `fields` 只取需要的字段。

注意：查询语句里不要有空格。

```javascript
async function main() {
  const customerCaseModel = getModel('customerCase')

  const query =
    'fields=' +
    customerCaseModel.title + ',' +
    customerCaseModel.type + ',' +
    customerCaseModel.introduce

  const list = await getTableList(customerCaseModel.modelId, query)

  console.log('精简字段列表:', list)
}

main()
```

如果还要加过滤条件，可以写成：

```javascript
const query =
  '?fields=' + customerCaseModel.title + ',' + customerCaseModel.type +
  '&' + customerCaseModel.type + '=客户案例'
```

说明：原文档示例里 `fields=` 没有写 `?`，实际项目中如果组合多个参数，建议按标准 query 写法带上 `?`。

## 8. 创建数据

### 8.1 创建一条数据

```javascript
async function main() {
  const studentModel = getModel('student')

  const createData = {}
  createData[studentModel.name] = '张三'
  createData[studentModel.gender] = '男'
  createData[studentModel.age] = 18

  const created = await createTableData(studentModel.modelId, createData)

  console.log('创建结果:', created)
}

main()
```

或：

```javascript
const created = await invokeModelApi(studentModel.modelId, 'create', 0, createData, 0)
```

### 8.2 批量创建

```javascript
async function main() {
  const studentModel = getModel('student')

  const dataList = [
    {
      [studentModel.name]: '张三',
      [studentModel.gender]: '男'
    },
    {
      [studentModel.name]: '李四',
      [studentModel.gender]: '女'
    }
  ]

  const createdList = await createTableData(studentModel.modelId, dataList)

  console.log('批量创建结果:', createdList)
}

main()
```

### 8.3 使用指定 ID 创建数据

有些场景需要先从后台获取预分配 ID，然后创建时带上 `assign_id`。

创建数据时：

```javascript
const createData = {
  assign_id: '后台预分配的数据ID',
  [studentModel.name]: '张三'
}

const created = await createTableData(studentModel.modelId, createData)
```

原文档提到获取预分配 ID 的接口格式：

```text
GET /app/api/{appId}/{modelId}/ID/
```

返回示例：

```json
{
  "msg": "ID retrieve success",
  "code": 200,
  "data": "gtgt3_mQvSjdnjng4Y2rZRtZ9v9Z"
}
```

## 9. 更新数据

### 9.1 更新一条数据

更新时必须带数据 ID。

```javascript
async function main() {
  const studentModel = getModel('student')
  const dataId = '替换为实际数据ID'

  const updateData = {
    id: dataId
  }
  updateData[studentModel.name] = '张三-已修改'

  const updated = await updateTableData(studentModel.modelId, updateData)

  console.log('更新结果:', updated)
}

main()
```

或：

```javascript
const updated = await invokeModelApi(studentModel.modelId, 'update', dataId, updateData, 0)
```

### 9.2 从当前行更新

表格详情、行内按钮等场景通常能拿到 `recordData`。

```javascript
async function main() {
  const workOrder = getModel('workOrder')

  const updateData = {}
  updateData[workOrder.status] = '已维修'

  await invokeModelApi(workOrder.modelId, 'update', recordData.id, updateData, 0)

  refreshTable()

  Message({
    type: 'success',
    message: '更新成功'
  })
}

main()
```

### 9.3 批量更新选中行

如果插件场景提供 `recordSelections`：

```javascript
async function main() {
  const purchaseList = getModel('purchaseList')

  if (!recordSelections || recordSelections.length === 0) {
    Message({
      type: 'warning',
      message: '请先选择数据'
    })
    return
  }

  for (const record of recordSelections) {
    const updateData = {}
    updateData[purchaseList.state] = '2'

    await invokeModelApi(purchaseList.modelId, 'update', record.id, updateData, 0)
  }

  refreshTable()

  Message({
    type: 'success',
    message: '批量更新成功'
  })
}

main()
```

如果是自定义表格组件，可以从组件属性获取选中行：

```javascript
const selectedRows = getValueByName({
  name: 'crCusTable_table_varProduct',
  type: 'elem',
  attr: 'attrs.attrs.selectedRows'
}) || []
```

## 10. 删除数据

### 10.1 删除一条数据

```javascript
async function main() {
  const studentModel = getModel('student')
  const dataId = '替换为实际数据ID'

  const result = await deleteTableData(studentModel.modelId, dataId)

  console.log('删除结果:', result)
}

main()
```

或：

```javascript
const result = await invokeModelApi(studentModel.modelId, 'delete', dataId, 0, 0)
```

### 10.2 确认后删除当前行

```javascript
async function main() {
  const studentModel = getModel('student')

  MessageBox.confirm('确定要删除当前数据吗？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(async function () {
    await deleteTableData(studentModel.modelId, recordData.id)

    refreshTable()

    Message({
      type: 'success',
      message: '删除成功'
    })
  })
}

main()
```

### 10.3 批量删除

`deleteTableData` 的第二个参数可以传 ID 数组。

```javascript
async function main() {
  const studentModel = getModel('student')

  const selectedRows = getValueByName({
    name: 'crCusTable_student',
    type: 'elem',
    attr: 'attrs.attrs.selectedRows'
  }) || []

  if (selectedRows.length === 0) {
    MessageBox.alert('请至少选择一条数据', '提示', {
      type: 'warning'
    })
    return
  }

  const ids = selectedRows.map(row => row.id)

  await deleteTableData(studentModel.modelId, ids)

  refreshTableData({
    tablename: 'crCusTable_student'
  })

  Message({
    type: 'success',
    message: '批量删除成功'
  })
}

main()
```

## 11. 获取表格选中行

### 11.1 使用 `recordSelections`

某些表格场景会直接把选中行传给插件：

```javascript
if (!recordSelections || recordSelections.length === 0) {
  Message({
    type: 'warning',
    message: '请先选择数据'
  })
  return
}

console.log('选中行:', recordSelections)
```

### 11.2 从高级表格组件取选中行

```javascript
function getSelectedRows() {
  const selectedRows = getValueByName({
    name: 'crCusTable_table_varProduct',
    type: 'elem',
    attr: 'attrs.attrs.selectedRows'
  }) || []

  if (selectedRows.length === 0) {
    MessageBox.alert('请至少选择一条数据', '提示', {
      type: 'warning'
    })
    return false
  }

  return selectedRows
}
```

## 13. 前端请求自定义接口

### 13.1 `requestWithToken`

用于带当前 token 调接口。

```javascript
async function main() {
  const res = await requestWithToken({
    url: '/app/crdata/kb/getKnowledge',
    method: 'POST',
    data: {
      pageSize: 20,
      page: 1
    }
  })

  console.log('接口返回:', res)
}

main()
```

### 13.2 分页接口参数习惯

前端传：

```javascript
{
  pageSize: 20,
  page: 1
}
```

后端一般转成：

```javascript
const limit = pageSize
const offset = (page - 1) * limit
```

## 14. 中台 `crmodel` 补充

前端插件里通常不直接用 `crmodel`，但后端插件 / 中台 flow 会用。

### 14.1 导入

```javascript
const crModel = global.get('crmodel')
```

### 14.2 查询

```javascript
const rows = await crModel.findAll('modelCodename', {
  where: {
    status: {
      [crModel.Op.eq]: '待处理'
    }
  },
  limit: 20,
  offset: 0,
  order: [['updatetime', 'DESC']]
}, context)
```

### 14.3 创建

```javascript
const created = await crModel.create('modelCodename', createData, {}, context)
```

### 14.4 更新

```javascript
const updatedCount = await crModel.update('modelCodename', updateData, {
  where: {
    id: {
      [crModel.Op.eq]: dataId
    }
  }
}, context)
```

### 14.5 删除

```javascript
const deletedCount = await crModel.destroy('modelCodename', {
  where: {
    id: {
      [crModel.Op.eq]: dataId
    }
  }
})
```

### 14.6 批量删除

```javascript
const deletedCount = await crModel.destroy('modelCodename', {
  where: {
    id: {
      [crModel.Op.in]: idList
    }
  }
})
```

注意：

- `app` 和 `model` 可以是 ID、程序标识或名称。
- 新 API 不建议传 `app`，能省略时可以省略。
- 查询默认可能有 `limit=2000`，需要全部数据时注意平台限制和性能风险。

## 15. 常见坑

### 15.1 更新数据忘记带 ID

错误写法：

```javascript
await updateTableData(studentModel.modelId, {
  [studentModel.name]: '张三'
})
```

推荐：

```javascript
await updateTableData(studentModel.modelId, {
  id: dataId,
  [studentModel.name]: '张三'
})
```

或：

```javascript
await invokeModelApi(studentModel.modelId, 'update', dataId, updateData, 0)
```

### 15.2 查询条件里字段名写错

不要手写 `ncfld_xxx`，优先用：

```javascript
const studentModel = getModel('student')
const query = '?' + studentModel.name + '__contains=张'
```

### 15.3 `getModel` 返回空

排查：

- 表单是否配置程序标识。
- 字段是否配置程序标识。
- 程序标识是否写错。
- 保存配置后是否刷新页面。

### 15.4 查询语句里有空格

原文档提醒：查询语句里不能有空格。

不推荐：

```javascript
const query = '?ncfld_xxx = 张三'
```

推荐：

```javascript
const query = '?ncfld_xxx=张三'
```

### 15.5 `forEach(async () => {})` 等待不可靠

不推荐：

```javascript
recordSelections.forEach(async function (record) {
  await invokeModelApi(modelId, 'update', record.id, data, 0)
})
```

推荐：

```javascript
for (const record of recordSelections) {
  await invokeModelApi(modelId, 'update', record.id, data, 0)
}
```

或并发：

```javascript
await Promise.all(recordSelections.map(function (record) {
  return invokeModelApi(modelId, 'update', record.id, data, 0)
}))
```

### 15.6 删除子表数据要用记录 ID 做关键条件

原文档提到：使用业务规则删除子表数据时，因为异步操作，需要以记录 ID 为关键过滤条件。

简单理解：

- 不要只靠页面临时状态定位子表数据。
- 删除时最好用父记录 ID / 子记录 ID 做明确过滤。

## 16. 常用代码片段

### 16.1 CRUD 基础模板

```javascript
async function main() {
  const model = getModel('student')

  const query = '?' + model.name + '__contains=张'
  const list = await getTableList(model.modelId, query)

  const createData = {
    [model.name]: '张三'
  }
  const created = await createTableData(model.modelId, createData)

  const updateData = {
    id: created.id,
    [model.name]: '张三-修改'
  }
  await updateTableData(model.modelId, updateData)

  await deleteTableData(model.modelId, created.id)
}

main()
```

### 16.2 查询后赋值给变量

```javascript
async function main() {
  const model = getModel('student')
  const list = await getTableList(model.modelId)

  setValueByName({
    name: 'VAR_studentList',
    type: 'var',
    value: list
  })
}

main()
```

### 16.3 选中行批量更新

```javascript
async function main() {
  const model = getModel('student')

  if (!recordSelections || recordSelections.length === 0) {
    Message({ type: 'warning', message: '请先选择数据' })
    return
  }

  for (const record of recordSelections) {
    const data = {}
    data[model.status] = '已处理'

    await invokeModelApi(model.modelId, 'update', record.id, data, 0)
  }

  refreshTable()
  Message({ type: 'success', message: '处理成功' })
}

main()
```

### 16.4 确认后删除

```javascript
async function main() {
  const model = getModel('student')

  MessageBox.confirm('确定删除吗？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(async function () {
    await deleteTableData(model.modelId, recordData.id)
    refreshTable()
    Message({ type: 'success', message: '删除成功' })
  })
}

main()
```

## 18. 推荐实践

1. 表单和字段先配置程序标识，再写插件。
2. 前端查询优先使用 `getModel + getTableList/getTableData`。
3. 创建和更新数据时，字段名优先来自 `getModel()`。
4. 更新必须带数据 ID。
5. 删除必须确认目标 ID，批量删除先校验选中行。
6. 查询条件不要写空格。
7. 大表查询优先加分页、排序和 `fields`。
8. 批量异步操作不要用 `forEach(async)`，用 `for...of` 或 `Promise.all`。
9. 操作成功后按场景调用 `refreshTable()` 或 `refreshTableData()`。
10. 中台批量操作注意 `limit`、权限上下文和性能风险。
