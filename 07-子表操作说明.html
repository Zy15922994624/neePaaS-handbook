07-子表操作说明 ​

整理日期：2026-05-17
适用范围：neePaaS / 闪搭前端插件 / 表单编辑 / 子表字段
目标：整理子表新增、修改、刷新、清空、校验、字段控制、映射选择和删除相关操作。

1. 这篇解决什么问题 ​

子表是表单开发里最容易写乱的部分。常见需求：

  • 读取当前表单里的子表数据。
  • 插入一条新的子表记录。
  • 修改某条子表记录。
  • 刷新某条子表记录，让页面同步更新。
  • 清空整个子表。
  • 根据用户选择自动插入子表记录。
  • 控制子表字段显示隐藏或只读。
  • 对子表数据做保存前校验。
  • 子表外键字段按当前行过滤。
  • 删除子表数据。

本篇主要覆盖前端插件里的子表操作。业务规则和后端插件只作为补充。

2. 子表相关变量和函数速查 ​

2.1 常用变量 ​

变量说明
recordData当前主表数据对象，包含主表字段和子表字段
childData表单编辑下子表新建时，当前插件对应的子表数据对象
childFieldId发生子表新建的主表中的子表字段 ID
eventFieldId字段值变化事件中，发生变化的字段 ID

2.2 常用函数 ​

函数说明
initNewChildData(childFieldId)初始化一条新的子表数据
appendChildData(newData, childFieldId)把子表数据插入到某个子表字段
refreshChildData(childData, childFieldId)刷新某条子表数据，触发页面同步和公式刷新
cleanupChildData(childFieldId)清空某个子表字段下所有数据
doPopupSelectAndMapping(...)调用子表映射弹窗选择并自动插入子表
setChildFieldsAttr(...)控制子表字段显隐或只读
setFkFieldFilter(..., recordData)给子表行内外键字段设置过滤条件

3. 子表数据结构 ​

子表字段在 recordData 里通常是一个数组。

示例：

javascript
recordData[mainModel.detailList] = [
  {
    id: 'detail_001',
    ncfld_name: '物料A',
    ncfld_qty: 10
  },
  {
    id: 'detail_002',
    ncfld_name: '物料B',
    ncfld_qty: 20
  }
]

读取子表：

javascript
const mainModel = getModel('purchaseOrder')
const childList = recordData[mainModel.detailList] || []

console.log('子表数据:', childList)

注意：

  • 主表里的子表字段值一般是数组。
  • 子表内字段也要用字段 ID，不要手写中文字段名。
  • 已保存的数据通常有 id。
  • 新增但未保存的数据可能没有正式 id，平台可能用内部状态字段维护。

4. 新增一条子表数据 ​

4.1 推荐方式：initNewChildData + appendChildData ​

这是平台提供的标准方式。它会初始化子表内字段默认值。

javascript
async function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childFieldId = mainModel.detailList

  const newData = await initNewChildData(childFieldId)

  newData[detailModel.materialName] = '物料A'
  newData[detailModel.quantity] = 10

  appendChildData(newData, childFieldId)
}

main()

4.2 为什么不建议直接 push ​

可以理解为平台对子表数据有自己的初始化和状态同步机制。

不推荐：

javascript
recordData[childFieldId].push({
  name: '物料A'
})

推荐：

javascript
const newData = await initNewChildData(childFieldId)
appendChildData(newData, childFieldId)

这样更容易触发表单视图同步、计算公式、外键字段刷新等平台逻辑。

5. 修改某条子表数据 ​

5.1 修改后刷新 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childFieldId = mainModel.detailList
  const childList = recordData[childFieldId] || []

  const target = childList[0]

  if (!target) return

  target[detailModel.quantity] = 100

  refreshChildData(target, childFieldId)
}

main()

5.2 按子表记录 ID 修改 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childFieldId = mainModel.detailList
  const childList = recordData[childFieldId] || []
  const targetId = '替换为子表记录ID'

  const target = childList.find(item => item.id === targetId)

  if (!target) {
    Message({
      type: 'warning',
      message: '未找到子表记录'
    })
    return
  }

  target[detailModel.quantity] = 100

  refreshChildData(target, childFieldId)
}

main()

5.3 批量修改子表数据 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childFieldId = mainModel.detailList
  const childList = recordData[childFieldId] || []

  childList.forEach(function (item) {
    item[detailModel.status] = '待处理'
    refreshChildData(item, childFieldId)
  })
}

main()

如果数据很多，逐条 refreshChildData 可能会有性能压力。可以先改数据，再根据实际表现决定是否只刷新关键行。

6. 清空子表 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')

  cleanupChildData(mainModel.detailList)
}

main()

适合：

  • 切换主表某个关键字段后，旧子表明细不再有效。
  • 用户点击“清空明细”按钮。
  • 重新从弹窗选择生成子表前，先清理旧数据。

建议清空前做确认：

javascript
function main() {
  const mainModel = getModel('purchaseOrder')

  MessageBox.confirm('确定清空所有明细吗？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(function () {
    cleanupChildData(mainModel.detailList)
  })
}

main()

7. 删除子表某一行 ​

前端插件没有在文档中明确给出单行删除函数。常见处理方式有两类：

7.1 编辑态临时删除：重建数组 ​

如果只是当前表单编辑态里删除某行，可以从 recordData[childFieldId] 过滤掉目标行，再根据平台表现决定是否需要刷新。

javascript
function main() {
  const mainModel = getModel('purchaseOrder')

  const childFieldId = mainModel.detailList
  const targetId = '替换为子表记录ID'
  const childList = recordData[childFieldId] || []

  recordData[childFieldId] = childList.filter(function (item) {
    return item.id !== targetId
  })
}

main()

注意：

  • 这种方式适合临时编辑态。
  • 如果平台未同步视图，优先考虑通过组件内置删除能力或业务规则处理。
  • 已保存子表数据最终删除是否落库，取决于平台保存机制。

7.2 业务规则删除：以记录 ID 为关键过滤条件 ​

原文档提醒：使用业务规则删除子表数据时，由于是异步操作，需要以【记录 ID】为关键过滤条件。

建议：

  • 不要只靠页面临时索引删除。
  • 删除条件里带主记录 ID 或子记录 ID。
  • 对已保存数据的删除，尽量使用明确 ID。

8. 根据用户选择自动插入子表记录 ​

8.1 使用子表映射 ​

如果你已经配置了子表映射，可以用：

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const productModel = getModel('product')

  doPopupSelectAndMapping({
    childFieldId: mainModel.detailList,
    modelId: productModel.modelId,
    title: '选择产品',
    filterQuery: '?' + productModel.status + '=启用'
  })
}

main()

这个函数会：

  1. 弹出目标表单选择数据。
  2. 用户选择数据。
  3. 根据子表字段上配置的映射关系，把数据复制到子表。

8.2 适合场景 ​

  • 从产品表选择多个产品，自动插入订单明细。
  • 从工序表选择工序，自动插入工艺路线明细。
  • 从物料表选择物料，自动插入领料明细。

8.3 和手写插入的区别 ​

方式适用情况
initNewChildData + appendChildData自己在插件里控制字段赋值
doPopupSelectAndMapping已经配置好子表映射，让平台自动复制字段

9. 弹窗选择后手动插入子表 ​

如果不使用子表映射，也可以用 selectTableItems 获取 ID，再自己查数据、插子表。

javascript
async function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')
  const productModel = getModel('product')

  const childFieldId = mainModel.detailList

  const selectedIds = await selectTableItems({
    modelId: productModel.modelId,
    multiple: true,
    defaultSelectType: 'empty',
    preSelectList: [],
    title: '选择产品',
    filterQuery: '?' + productModel.status + '=启用'
  })

  if (!selectedIds || selectedIds.length === 0) return

  for (const productId of selectedIds) {
    const product = await getTableData(productModel.modelId, productId)
    const newData = await initNewChildData(childFieldId)

    newData[detailModel.product] = product.id
    newData[detailModel.productName] = product[productModel.name]
    newData[detailModel.quantity] = 1

    appendChildData(newData, childFieldId)
  }
}

main()

优点：

  • 逻辑完全可控。
  • 可以做复杂转换。

缺点：

  • 代码更多。
  • 字段映射要自己维护。

10. 子表外键字段过滤 ​

子表里的外键字段需要按当前子表行做过滤时，使用 setFkFieldFilter 的第三个参数。

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const materialModel = getModel('material')

  const fkFieldId = mainModel.materialFk
  const materialType = recordData[mainModel.materialType]

  if (!materialType) return

  const queryStr = '?' + materialModel.type + '=' + materialType

  setFkFieldFilter(fkFieldId, queryStr, recordData)
}

main()

重点：

  • 第一个参数是子表中的外键字段 ID。
  • 第二个参数是针对外表的过滤条件。
  • 第三个参数是当前子表行 recordData。

11. 子表字段显示隐藏和只读 ​

11.1 隐藏单个字段 ​

javascript
setChildFieldsAttr(childField, subChildField, 'show', false)

11.2 显示单个字段 ​

javascript
setChildFieldsAttr(childField, subChildField, 'show', true)

11.3 设置只读 ​

javascript
setChildFieldsAttr(childField, subChildField, 'editable', false)

11.4 恢复可编辑 ​

javascript
setChildFieldsAttr(childField, subChildField, 'editable', true)

11.5 控制多个字段 ​

javascript
setChildFieldsAttr(childField, [subInput, subNumber, subSelect, subDate], 'show', false)

11.6 控制所有字段 ​

javascript
setChildFieldsAttr(childField, 'all', 'show', false)

11.7 根据主表字段动态控制 ​

javascript
function main() {
  const mainModel = getModel('mainTable')
  const childField = mainModel.detailList

  const subInput = '子表字段ID_1'
  const subNumber = '子表字段ID_2'
  const subSelect = '子表字段ID_3'

  if (recordData[eventFieldId] === '1') {
    setChildFieldsAttr(childField, [subInput, subNumber, subSelect], 'show', true)
  } else {
    setChildFieldsAttr(childField, [subInput, subNumber, subSelect], 'show', false)
  }
}

main()

适合场景：

  • 模式为“详情”时展示更多子表字段。
  • 模式为“精简”时隐藏部分字段。
  • 根据主表状态控制子表是否可编辑。

12. 子表数据校验 ​

表单保存前，可以在校验插件中检查子表数据。

12.1 校验子表不能为空 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const childList = recordData[mainModel.detailList] || []

  if (childList.length === 0) {
    return [false, '请至少添加一条明细']
  }

  return [true, '']
}

return main()

12.2 校验子表数量合计 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childList = recordData[mainModel.detailList] || []

  let total = 0

  childList.forEach(function (item) {
    total += Number(item[detailModel.quantity] || 0)
  })

  if (total > 100) {
    return [false, '明细总数量不能大于100']
  }

  return [true, '']
}

return main()

12.3 校验子表必填字段 ​

javascript
function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const childList = recordData[mainModel.detailList] || []

  for (let i = 0; i < childList.length; i++) {
    const item = childList[i]

    if (!item[detailModel.material]) {
      return [false, '第' + (i + 1) + '行明细未选择物料']
    }

    if (!item[detailModel.quantity]) {
      return [false, '第' + (i + 1) + '行明细未填写数量']
    }
  }

  return [true, '']
}

return main()

12.4 异步校验子表外键数据 ​

javascript
async function main() {
  const mainModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')
  const materialModel = getModel('material')

  const childList = recordData[mainModel.detailList] || []

  for (let i = 0; i < childList.length; i++) {
    const item = childList[i]
    const materialId = item[detailModel.material]

    if (!materialId) continue

    const material = await getTableData(materialModel.modelId, materialId)

    if (material && material[materialModel.status] !== '启用') {
      return [false, '第' + (i + 1) + '行物料未启用']
    }
  }

  return [true, '']
}

return main()

13. 使用 doAnyModelOp 创建含子表的数据 ​

doAnyModelOp 可以弹出一个新的弹框，对指定表单做操作。

子表字段的值是列表，列表中的每个数据都必须包含：

javascript
status: 'created'

示例：

javascript
function main() {
  const orderModel = getModel('purchaseOrder')
  const detailModel = getModel('purchaseOrderDetail')

  const data = {}
  data[orderModel.title] = '采购订单'
  data[orderModel.detailList] = [
    {
      status: 'created',
      [detailModel.materialName]: '物料A',
      [detailModel.quantity]: 10
    }
  ]

  doAnyModelOp({
    modelId: orderModel.modelId,
    operation: 'create',
    data: data
  })
}

main()

适合：

  • 从一个页面打开另一个表单的新建弹框。
  • 预填主表和子表默认数据。

14. 常见坑 ​

14.1 直接改子表数组后页面不刷新 ​

如果直接修改：

javascript
recordData[childFieldId][0][fieldId] = 100

页面不一定刷新。建议调用：

javascript
refreshChildData(recordData[childFieldId][0], childFieldId)

14.2 新增子表不要手写空对象 ​

不推荐：

javascript
appendChildData({}, childFieldId)

推荐：

javascript
const newData = await initNewChildData(childFieldId)
appendChildData(newData, childFieldId)

14.3 子表外键过滤忘记传 recordData ​

子表行内过滤要写：

javascript
setFkFieldFilter(fkFieldId, queryStr, recordData)

否则可能无法区分当前行。

14.4 删除子表不要只靠索引 ​

索引可能因为排序、过滤、异步刷新变化。

建议：

  • 已保存数据按 id 删除。
  • 业务规则删除用记录 ID 做关键过滤条件。

14.5 子表映射不生效 ​

排查：

  • 子表字段 ID 是否正确。
  • 弹窗目标表单 ID 是否正确。
  • 字段映射关系是否配置。
  • 过滤条件是否导致弹窗没有数据。
  • 保存配置后是否刷新页面或清缓存。

14.6 校验插件必须返回数组 ​

表单校验通常需要返回：

javascript
[true, '']

或：

javascript
[false, '错误提示']

异步校验时：

javascript
return main()

其中 main 是 async 函数并返回上述数组。

17. 推荐实践 ​

  1. 新增子表行优先用 initNewChildData + appendChildData。
  2. 修改子表行后用 refreshChildData 同步页面。
  3. 清空子表用 cleanupChildData。
  4. 子表外键过滤记得传第三个参数 recordData。
  5. 子表映射已配置时，用 doPopupSelectAndMapping。
  6. 自己控制字段映射时，用 selectTableItems + initNewChildData。
  7. 子表字段显隐/只读用 setChildFieldsAttr。
  8. 保存前校验子表数据，返回 [true, ''] 或 [false, '提示']。
  9. 删除已保存子表数据时，优先用记录 ID 定位。
  10. 遇到子表不同步，先检查是否调用了平台提供的刷新/追加函数。
