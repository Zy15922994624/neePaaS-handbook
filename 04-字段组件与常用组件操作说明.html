04-字段组件与常用组件操作说明 ​

适用对象：表单基础字段、系统字段、扫码组件、日历组件、看板组件、数据编辑组件、双列组件、选项卡、轮播图、树形组件、表单过滤组件。

这篇只整理在线文档中明确出现过的组件能力、配置项和插件示例。表格、List、弹窗、父子页面通信已经在前面章节单独整理，这里只补常用组件层面的操作说明。

1. 表单组件快速创建 ​

表单组件支持两种快速创建方式：

  • 智能表单识别。
  • 在文本框按格式填写。

1.1 智能表单识别 ​

适用场景：

  • 已经有表单图片。
  • 想把图片中的字段快速识别成表单字段。

流程：

  1. 点击智能表单识别按钮。
  2. 选择需要识别的表单图片。
  3. 打开图片后，系统自动识别字段。
  4. 调整字段格式和顺序。
  5. 点击确认，字段会出现在表单编辑区。

1.2 文本快速创建 ​

文本框格式：

text
字段名，字段类型

目前文档中明确提到支持：

  • 文字
  • 数字
  • 开关

示例：

text
姓名，文字
年龄，数字
是否启用，开关

2. 基础组件通用属性 ​

基础组件是表单里最常用的一类字段。

在线文档中提到的通用属性包括：

  • 标题。
  • 宽度。
  • 占位内容。
  • 支持二维码扫码。
  • 支持条形扫码。
  • 默认值。
  • 后缀内容。
  • 数据绑定 key。
  • 自动填写。
  • 超宽缩略显示。
  • 建立数据索引。
  • 操作属性。
  • 条件显示。
  • 校验。
  • 插件计算。

2.1 操作属性 ​

在线文档提到的操作属性：

  • 禁用：勾选后，组件输入框变为禁用状态，不能输入。
  • 文本框可输入：默认可输入；未勾选时输入框不可输入。
  • 编辑可见：表单编辑时是否可见。
  • 编辑只读：表单编辑时是否只读。
  • 详情可见：表单详情时是否显示。
  • 清除按钮：编辑时是否有清除按钮。

2.2 条件显示 ​

条件显示用于控制组件在表单编辑时，满足什么条件才显示。

配置项：

  • 选择前置字段。
  • 条件类型。

条件类型包括：

  • 单值：前置组件等于某个值时显示。
  • 多值：前置组件等于多个值中的任意一个时显示。
  • 范围：前置组件在设定范围中时显示。

2.3 校验 ​

在线文档提到的字段校验项：

  • 必填：不填写时无法保存。
  • 唯一：值不能重复，重复时报错。
  • 字符串：校验是否为字符串类型。
  • HTTP网页地址：校验是否为 HTTP 网页地址。
  • 邮箱地址：校验是否为邮箱地址。

如果是更复杂的保存前校验，使用前端表单校验插件，详见第 08 篇。

3. 单行文本、多行文本、图文 ​

3.1 单行文本 ​

适用场景：

  • 姓名。
  • 工厂名称。
  • 电话。
  • 简短备注。

重点属性：

  • 占位内容。
  • 默认值。
  • 后缀内容。
  • 校验。
  • 条件显示。

3.2 多行文本 ​

适用场景：

  • 产品详情。
  • 会议摘要。
  • 日报周报。
  • 较长说明。

文档说明：可通过调整组件宽度，调整每行显示字数，默认输入时显示五行。

3.3 图文 ​

适用场景：

  • 规章制度。
  • 需要一定格式的说明文本。
  • 富文本类内容。

4. 数字组件 ​

数字组件用于输入数字或做计算，只允许录入数字。

在线文档提到的特殊属性：

  • 最小值。
  • 最大值。
  • 步长。
  • 数据显示精度。
  • 数据存储精度。
  • 基值。
  • 倍数值。
  • 默认值。
  • 单位名称。
  • 支持条件样式。
  • 支持自定义显示格式。
  • 控制按钮。
  • 计算插件。

4.1 最小值、最大值 ​

用于限制输入范围，可为负数。

4.2 步长 ​

控制点击增减按钮时数字变化幅度。

例如步长设置为 0.1，点击增加按钮时，数值加 0.1。

4.3 显示精度与存储精度 ​

  • 数据显示精度：页面显示的小数位数。
  • 数据存储精度：后台保存的小数位数。

4.4 单位名称 ​

用于显示数字单位，例如：

  • g
  • 斤
  • 米
  • 个

4.5 自定义显示格式 ​

在线文档说明：数字组件属性中打开“支持自定义显示”后，可以在自定义显示格式页面中使用 value 处理当前数字，并通过 return 返回显示结果。

数值乘以 2 显示 ​

javascript
return value * 2

分钟转换为“天 时 分” ​

javascript
let mm = (value % 60).toFixed(0).toString()
mm = mm + '分'

let hh = (parseInt(value / 60) % 24).toString()
hh = hh + '时'

let dd = parseInt(value / 1440).toString()
dd = dd + '天'

return dd + ' ' + hh + mm

注意：这个能力用于显示格式处理，不等同于修改真实保存值。

在线文档提到的属性：

5.2 单选框组 ​

适用场景：

  • 性别。
  • 满意度。
  • 单个结果选择。

在线文档提到：

  • 按钮模式有点选和按钮两种。
  • 布局方式有块级和行内两种。

5.3 多选框组 ​

适用场景：

  • 多选题。
  • 喜欢的产品。
  • 多标签选择。

在线文档提到：

  • 布局方式有竖排和横排。
  • 选项操作参见下拉选择框。

5.4 开关 ​

适用场景：

  • 是否同意。
  • 是否启用。
  • 是否超预算。

文档说明：开关显示为蓝色即为是，灰色即为否。

6.1 时间选择器 ​

适用场景：

在线文档提到：

  • 固定选项模式下需要设置起始时间、结束时间、选项间时间距离。

6.2 日期选择器 ​

适用场景：

  • 入职日期。
  • 产品入库日期。
  • 业务开始时间。
  • 日期时间选择。

在线文档提到日期选择器有四种显示类型：

  • 年。
  • 月。
  • 日。
  • 日期时间。

6.3 日期可选范围 ​

在线文档说明：日期可选范围插件需要在 pageEnter，也就是组件渲染后调用。

设置路径：

javascript
attrs.attrs.disabledDate

disabledDate(time) 返回 true 表示不可选，返回 false 表示可选。

javascript
let disabledDate = time => {
  return dayjs(time).diff('2022-11-9', 'days') > 0
}

setValueByName({
  name: 'crDate_testDate',
  type: 'elem',
  attr: 'attrs.attrs.disabledDate',
  value: disabledDate
})

8. 系统组件 ​

系统字段是系统自动生成的字段。

在线文档提到的系统组件包括：

  • 创建人。
  • 审批状态。
  • 序列号。
  • 创建时间。
  • 更新时间。
  • 人员。
  • 部门。
  • 角色。
  • 读权限人。
  • 读权限组。
  • 写权限人。
  • 写权限组。

8.1 创建人 ​

系统自动生成，显示新增数据的创建人，无法修改。

一个表单只能有一个创建人控件。

8.2 审批状态 ​

用于显示有审批流的表单记录的审批状态。

8.3 序列号 ​

系统自动生成且唯一，可用于：

  • 流水号。
  • 订单号。
  • 唯一编号。

在线文档提到的配置：

  • 前缀字符。
  • 格式。
  • 自增数字长度。
  • 重置周期。

格式支持：

  • 无。
  • 年。
  • 年月。
  • 年月日。
  • 年周。
  • 年周日。

重置周期包括：

  • 不重置。
  • 每天重置。
  • 每周重置。
  • 每月重置。
  • 每年重置。

8.4 创建时间和更新时间 ​

  • 创建时间：系统自动生成，显示新增数据的创建时间，无法修改。
  • 更新时间：系统自动生成，显示数据修改时间，无法修改。

在线文档说明：业务规则进行更新或插入时，同样会引起修改时间改变。

8.5 人员、部门、角色 ​

适用场景：

  • 责任人。
  • 部门领导。
  • 人事部、业务部。
  • 维修工等角色。

人员组件实际编辑时，可选择人员管理中的人员。

8.6 读写权限字段 ​

在线文档提到：

  • 读权限人：只有读取权限，没有编辑权限的人员。
  • 读权限组：只有读取权限，没有编辑权限的部门或角色。
  • 写权限人：有读取和编辑权限的人员。
  • 写权限组：有读取和编辑权限的部门或角色。

9. 扫码组件 ​

扫码组件需要在应用管理页面中添加，类型选择 扫码组件。

9.1 扫码设置 ​

进入扫码组件后，点击右上角“扫码设置”。

在线文档提到的配置：

  • 扫码设备。
  • 编码类型。
  • 组件类型。

扫码设备目前支持：

  • 扫码枪。
  • 摄像头。

编码类型目前文档中提到仅限二维码。

组件类型有三种：

  • 更新数据。
  • 显示数据。
  • 远程插件。

9.2 更新数据 ​

用于扫码后更新表单数据。

配置步骤：

  1. 选择源数据表单，用于提供数据。
  2. 选择目标数据表单，用于接收数据。
  3. 选择操作类型。

操作类型包括：

  • 插入。
  • 更新。
  • 删除。

插入 ​

选择插入时，会出现赋值设置。

赋值设置包括：

  • 固定值。
  • 选择键值。
  • 本表字段。
  • 指向本表记录。

更新 ​

选择更新时，在赋值设置基础上，还会出现过滤条件。

过滤条件包括：

  • 相等。
  • 大于。
  • 小于。
  • 大于等于。
  • 小于等于。

文档提醒：需要选择已有数据的字段进行赋值操作。

删除 ​

选择删除时，只出现目标过滤条件。

目标数据表字段符合过滤条件后，该字段会被删除。

9.3 显示数据 ​

扫码后显示表单内容。

需要配置：

  • 显示表单。
  • 显示类型。

显示表单可选：

  • 任意表单。
  • 指定表单。

显示类型可选：

  • 显示数据详情。
  • 显示图片附件。

9.4 远程插件 ​

用于选择第三方插件，让扫码逻辑更个性化。

配置步骤：

  1. 选择需要操作的数据表单。
  2. 选择需要的远程插件。

在线文档提醒：远程插件是前台 API 接口组件，使用前必须有一个设置好的 API 接口组件文件。

10. 表单过滤组件 ​

表单过滤组件可以通过 UI 配置，也可以通过插件动态配置搜索字段列表。

g.e.crTableSearch_z_G4.set.attrs.attrs.buttonList = [

javascript
let fields = [

]

g.e.crTableSearch_z_G4.set.attrs.attrs.fields = fields

10.3 修改字段编辑属性 ​

javascript
fields[0].attrs.label = '用户名称'
fields[0].attrs.placeholder = '请输入要查询的用户名称'
fields[1].attrs.multiple = false

g.e.crTableSearch_z_G4.set.attrs.attrs.fields = fields

10.4 外键远程搜索过滤 ​

文档说明：当 remoteSearch 为 false 时触发远程搜索，可以在 filter 里写过滤条件。

javascript
fields[0].attrs.remoteSearch = false
fields[0].attrs.filter = '?ncfld_m6L236vJ8SRuL4oeZhDWQo=2'

g.e.crTableSearch_hgXn.set.attrs.attrs.fields = fields

当 remoteSearch 为 true 时取消远程搜索。

javascript
fields[0].attrs.remoteSearch = true

g.e.crTableSearch_hgXn.set.attrs.attrs.fields = fields

10.5 常用属性 ​

整体属性：

  • attrs.attrs.value：实时查询 form data value object。
  • attrs.attrs.queryStr：生成的查询字符串。
  • attrs.attrs.layoutColumn：一行列数。
  • attrs.attrs.labelPosition：标签对齐，可选 top、left、right。
  • attrs.attrs.fields：字段配置。
  • attrs.attrs.buttonList：按钮配置。

字段对象属性：

  • prop：字段 ID。
  • type：字段类型。
  • attrs：组件属性。
  • dictMap：数据字典映射。

事件：

  • change：值变化，参数 { value, queryStr }。
  • reset：重置按钮点击。
  • search：搜索按钮点击，参数 { value, queryStr }。
  • mouseover：鼠标移入。
  • mouseout：鼠标移出。

11. 动态控制选项卡 ​

在线文档示例：通过设置选项卡组件的 attrs.attrs.options 动态控制选项。

javascript
let options = [
  { value: 'tabs1' }
]

setValueByName({
  name: 'mHdrTabs_xxxx',

})

适用场景：

  • 接口返回多少个分类，就展示多少个选项卡。
  • 根据权限控制可见 Tab。
  • 根据业务状态展示不同 Tab。

12. 轮播图 Swiper ​

Swiper 组件支持绑定数据表或变量。

在线文档提到的配置能力：

  • 数据绑定。
  • 移动方向。
  • 自动播放。
  • 循环。
  • 分页。
  • 导航。
  • 同屏显示页数。

12.1 数据绑定 ​

支持：

  • 绑定数据表。
  • 绑定变量。

12.2 移动方向 ​

支持：

  • 水平方向移动。
  • 垂直方向移动。

12.3 自动播放 ​

打开自动播放后，会根据播放延时自动切换下一张内容。

关闭自动播放后，只能手动切换。

12.4 循环 ​

打开循环后，最后一页内容后衔接第一页。

关闭循环后，最后一页后为空。

12.5 分页和导航 ​

分页：

  • 水平移动时分页栏在组件下方。
  • 垂直移动时分页栏在组件右侧。

导航：

  • 打开后页面左右两侧出现导航按钮。
  • 关闭后无导航按钮。

12.6 同屏显示页数 ​

在线文档说明：

  • 默认同屏显示 1 页。
  • 支持 1-8 页。

13. 树形组件 HTML 渲染 ​

在线文档说明：树形组件比较特殊，只有一列 col 数据，不支持 col 变量配置，直接配置 render 属性。

示例：

javascript
g.e.crTree_devTree.set.attrs.attrs.render = (row, colFieldId) => {
  let opacity = 1
  let iconUrl

  if (row.rowType === 'device') {
    iconUrl = '/dfs/group1/M00/00/6F/wKgA9WXVvouAZ5ZNAAAD0BP3eRk121.png'
  } else {
    iconUrl = '/dfs/group1/M00/00/6C/wKgA9WXDN_CATy6TAAADxb9l944411.png'
  }

  const html = `<div style="display: flex; align-items: center;">
    <img style="height: 15px; opacity: ${opacity}" src="${iconUrl}">
    <span style="margin-left: 5px; opacity: ${opacity}">${row[colFieldId]}</span>
  </div>`

  return html
}

注意：

  • row 是当前树节点数据。
  • colFieldId 是当前列字段。
  • 返回值是 HTML 字符串。

在线文档说明：行内编辑的多语言主要通过 dictMap 设置，可以根据数据字典设置：

  • 列 label。
  • options。
  • attrs.placeholder。

示例片段：

json
{
  "label": "日期时间选择",

19. 常见坑 ​

19.1 数字自定义显示误以为会改保存值 ​

数字自定义显示使用 return 返回展示结果，主要影响显示格式，不等同于修改真实保存值。

19.2 日期 disabledDate 返回值写反 ​

disabledDate 返回：

  • true：不可选。
  • false：可选。

19.3 表单过滤组件 prop 写错 ​

fields[].prop 是字段 ID，不是字段中文名。

javascript
{
  prop: 'ncfld_xxx',
  type: 'input',
  attrs: {}
}

19.4 表单过滤组件改完 fields 没重新赋值 ​

修改 fields 数组后，需要重新写回组件。

javascript
g.e.crTableSearch_z_G4.set.attrs.attrs.fields = fields

19.5 扫码远程插件前没有 API 接口组件文件 ​

文档明确提醒：远程插件是前台 API 接口组件，使用前必须有设置好的 API 接口组件文件。

19.6 数据编辑组件重复点击保存 ​

文档提醒：多次点击保存，会保存多条相同数据记录。

20. 排查顺序 ​

组件配置不生效时，按这个顺序查：

  1. 确认组件名是否正确。
  2. 确认属性路径是否正确，例如 attrs.attrs.options、attrs.attrs.fields。
  3. 确认字段 ID 是否正确，不要把中文字段名当作 prop。
  4. 动态设置数组后，确认是否重新写回组件。
  5. 日期可选范围确认插件是否在 pageEnter 调用。
  6. 扫码组件确认组件类型是更新数据、显示数据还是远程插件。
  7. 远程插件确认 API 接口组件文件已配置。
  8. 表单过滤组件事件里打印 { value, queryStr }。
  9. 树形组件 HTML 渲染先打印 row 和 colFieldId。
  10. Swiper 先确认绑定的是数据表还是变量。
