08-外键过滤与弹窗选择操作说明 ​

整理日期：2026-05-17
适用范围：neePaaS / 闪搭前端插件 / 闪用前端插件 / 外键字段 / 快速过滤 / 弹窗选择
目标：整理外键字段过滤、外键选项获取、快速过滤、弹窗选择和子表映射相关的常用写法。

1. 这篇解决什么问题 ​

外键和过滤相关问题很常见，但容易混淆，因为不同场景使用的函数不同。

常见需求：

  • 表单编辑页面里，给某个外键字段设置可选范围。
  • 子表里的外键字段，需要根据当前子表行做不同过滤。
  • 表格详情页里，给快速过滤字段的外键下拉框设置可选范围。
  • 闪用页面里，给 select 组件塞入外键选项。
  • 通用搜索组件 tableSearch 的外键搜索下拉框需要过滤。
  • 弹出表单选择窗口，让用户选择数据并带回 ID。
  • 调用子表映射配置，把弹窗选择结果自动插入子表。
  • 组件绑定数据表后，需要设置过滤并刷新。

先记住这张选择指南：

场景推荐函数
表单编辑页外键字段过滤setFkFieldFilter
子表行内外键字段过滤setFkFieldFilter(fkFieldId, queryStr, recordData)
表格详情快速过滤外键字段过滤setQuickFilterFkFilter
给快速过滤字段设置默认值setQuickFilterValue
给表单页面增加额外过滤条件setTableExtraQuery
获取当前表格查询条件getTableQuery
弹出表单选择数据selectTableItems
调用子表映射弹窗选择doPopupSelectAndMapping
闪用 select 组件设置外键选项getFkOptions / setFkSelectOptions
组件绑定数据表后过滤setTableFilter + refreshTableData

2. 查询字符串格式 ​

外键过滤本质上还是查询过滤，格式和表单查询一致。

等于：

text
?字段ID=值

包含：

text
?字段ID__contains=值

大于：

text
?字段ID__gt=3

多个条件并且：

text
?字段A=值A&字段B=值B

多个条件或者：

text
?字段A=值A|字段B=值B

注意：

  • 查询字符串不要有空格。
  • 第一个参数通常以 ? 开头。
  • 如果函数内部会拼接到已有 query 后面，有些场景可以用 & 开头，具体看函数说明。
  • 字段 ID 建议通过 getModel() 获取，不要手写。

3. 表单编辑页：外键字段过滤 ​

3.1 适用场景 ​

在 表单编辑 场景下：

  • 字段初始化
  • 字段值变化
  • 按钮点击

调用：

javascript
setFkFieldFilter(fkFieldId, queryStr)

用于控制某个外键字段的候选数据。

3.2 基础写法 ​

假设主表里有一个外键字段 factoryFk，指向工厂表。现在只允许选择类型为 small 的工厂。

javascript
function main() {
  const mainModel = getModel('mainTable')
  const factoryModel = getModel('factory')

  const fkFieldId = mainModel.factoryFk
  const queryStr = '?' + factoryModel.type + '=small'

  setFkFieldFilter(fkFieldId, queryStr)
}

main()

3.3 文本包含过滤 ​

javascript
const queryStr = '?' + factoryModel.name + '__contains=上海'
setFkFieldFilter(mainModel.factoryFk, queryStr)

3.4 数字大小过滤 ​

javascript
const queryStr = '?' + factoryModel.level + '__gt=3'
setFkFieldFilter(mainModel.factoryFk, queryStr)

3.5 根据当前表单字段动态过滤 ​

例如先选择区域，再过滤工厂。

javascript
function main() {
  const mainModel = getModel('mainTable')
  const factoryModel = getModel('factory')

  const currentArea = recordData[mainModel.area]

  if (!currentArea) {
    setFkFieldFilter(mainModel.factoryFk, '?id__isnull=True')
    return
  }

  const queryStr = '?' + factoryModel.area + '=' + currentArea

  setFkFieldFilter(mainModel.factoryFk, queryStr)
}

main()

说明：

  • recordData 是当前表单数据对象。
  • 外键字段值通常是被关联数据的 ID。

4. 子表行内外键过滤 ​

4.1 适用场景 ​

当外键字段在子表里，并且每一行的过滤条件不同，需要传第三个参数 recordData。

javascript
setFkFieldFilter(fkFieldId, queryStr, recordData)

这里的 recordData 表示对应子表行数据。

4.2 基础写法 ​

javascript
function main() {
  const mainModel = getModel('mainTable')
  const materialModel = getModel('material')

  const fkFieldId = mainModel.materialFk
  const queryStr = '?' + materialModel.type + '=steel'

  setFkFieldFilter(fkFieldId, queryStr, recordData)
}

main()

4.3 根据当前子表行字段过滤 ​

javascript
function main() {
  const mainModel = getModel('mainTable')
  const materialModel = getModel('material')

  const materialType = recordData[mainModel.materialType]

  if (!materialType) return

  const queryStr = '?' + materialModel.type + '=' + materialType

  setFkFieldFilter(mainModel.materialFk, queryStr, recordData)
}

main()

注意：

  • 子表行内过滤时，第三个参数非常关键。
  • 不传第三个参数，可能会影响所有行，或者无法按当前行区分。

5. 表格详情：快速过滤外键字段过滤 ​

5.1 适用场景 ​

在 表格详情 场景的 页面初始化 事件下，给快速过滤里的外键字段设置候选范围。

使用：

javascript
setQuickFilterFkFilter(fkFieldId, queryStr)

5.2 基础写法 ​

下面例子：主表有一个工厂外键快速过滤字段，只展示工厂表里 type=small 的工厂。

javascript
function main() {
  const mainModel = getModel('mainTable')
  const factoryModel = getModel('factory')

  const fkFieldId = mainModel.factoryFk
  const queryStr = '?' + factoryModel.type + '=small'

  setQuickFilterFkFilter(fkFieldId, queryStr)
}

main()

原文档里提醒：如果没有其他过滤参数，开始字符用 ?；如果接在已有过滤后面，用 &。

5.3 设置快速过滤默认值 ​

javascript
function main() {
  const mainModel = getModel('mainTable')

  setQuickFilterValue(mainModel.status, '待处理')
}

main()

外键或日期等字段可能支持数组值：

javascript
setQuickFilterValue(mainModel.factoryFk, ['factory_001', 'factory_002'])

5.4 给表格增加额外过滤条件 ​

javascript
function main() {
  const mainModel = getModel('mainTable')

  const queryStr = '?' + mainModel.status + '=待处理'

  setTableExtraQuery(queryStr)
}

main()

5.5 获取当前过滤条件 ​

javascript
async function main() {
  const queryList = await getTableQuery()

  console.log('当前查询条件:', queryList)
}

main()

返回示例类似：

javascript
[
  ['search', '南通市'],
  ['ncfld_xxx__in', '高,中,低']
]

6. 闪用页面：给 select 设置外键选项 ​

6.1 使用 getFkOptions ​

getFkOptions(modelId, query) 会查询外表数据，并返回适合 select 使用的选项数组。

javascript
async function main() {
  const equipmentModel = getModel('equipment')

  const query = '?' + equipmentModel.status + '=free'
  const options = await getFkOptions(equipmentModel.modelId, query)

  setValueByName({
    name: 'crSelect_equipment',
    type: 'elem',
    attr: 'attrs.attrs.options',
    value: options
  })
}

main()

返回结构通常类似：

javascript
[
  { label: '设备A', value: '设备A_ID' },
  { label: '设备B', value: '设备B_ID' }
]

6.2 使用 setFkSelectOptions ​

如果只是把过滤后的外键选项直接塞到 select 组件，可以用：

javascript
async function main() {
  const equipmentModel = getModel('equipment')
  const query = '?' + equipmentModel.status + '=free'

  await setFkSelectOptions('crSelect_equipment', equipmentModel.modelId, query)
}

main()

参数：

  • 第一个参数：select 组件名称
  • 第二个参数：外表 modelId
  • 第三个参数：过滤条件

7. tableSearch 外键过滤 ​

7.1 适用场景 ​

通用列表或搜索组件中，外键字段默认展示全部选项。如果需要人工预处理下拉框内容，需要在对应字段配置里加入 filter。

7.2 动态设置字段配置 ​

javascript
function main() {
  const fields = [
    {
      prop: 'ncfld_factoryFk',
      type: 'foreignkey',
      attrs: {
        label: '工厂',
        clearable: true,
        multiple: true,
        filterable: true,
        collapseTags: true,
        disabled: false,
        size: 'mini',
        placeholder: '请选择',
        remoteSearch: false,
        filter: '?ncfld_type=small'
      },
      dictMap: []
    }
  ]

  setValueByName({
    name: 'crTableSearch_factory',
    type: 'elem',
    attr: 'attrs.attrs.fields',
    value: fields
  })
}

main()

7.3 remoteSearch 的含义 ​

文档里的描述：

  • remoteSearch = false 时，触发远程搜索，可在 filter 里写过滤条件。
  • remoteSearch = true 时，取消远程搜索。

如果实际表现与预期不一致，先打印组件字段配置：

javascript
const fields = getValueByName({
  name: 'crTableSearch_factory',
  type: 'elem',
  attr: 'attrs.attrs.fields'
})

console.log('搜索字段配置:', fields)

8. 组件绑定数据表后的过滤 ​

8.1 基础写法 ​

如果组件绑定了资源库里的 Table，可以用：

javascript
setTableFilter({ tablename, queryString })
refreshTableData({ tablename })

8.2 示例 ​

javascript
async function main() {
  const tablename = 'TBL_student'
  const studentModel = getModel('student')

  const queryString = '?' + studentModel.gender + '=男'

  setTableFilter({
    tablename: tablename,
    queryString: queryString
  })

  await refreshTableData({
    tablename: tablename
  })
}

main()

注意：

  • tablename 是资源库里定义的 Table 名称，不一定是组件名。
  • 设置过滤后需要刷新数据。

9. 弹窗选择表单数据 ​

9.1 使用 selectTableItems ​

用于弹出表单数据选择对话框，用户选择后返回数据 ID 数组。

javascript
async function main() {
  const materialModel = getModel('material')

  const selectedIds = await selectTableItems({
    modelId: materialModel.modelId,
    multiple: true,
    defaultSelectType: 'empty',
    preSelectList: [],
    title: '选择物料',
    filterQuery: '?' + materialModel.status + '=启用'
  })

  console.log('用户选择的数据ID:', selectedIds)
}

main()

9.2 参数说明 ​

  • modelId：要弹出的表单 ID。
  • multiple：是否多选。
  • defaultSelectType：默认选择方式，常见值有 empty、first、all、list。
  • preSelectList：预选 ID 数组。
  • title：弹窗标题。
  • filterQuery：弹窗表单预过滤条件。

9.3 单选 ​

javascript
async function main() {
  const customerModel = getModel('customer')

  const selectedIds = await selectTableItems({
    modelId: customerModel.modelId,
    multiple: false,
    defaultSelectType: 'empty',
    preSelectList: [],
    title: '选择客户',
    filterQuery: '?' + customerModel.status + '=有效'
  })

  const selectedId = selectedIds && selectedIds[0]

  console.log('选择客户ID:', selectedId)
}

main()

9.4 选择后查询完整数据 ​

javascript
async function main() {
  const customerModel = getModel('customer')

  const selectedIds = await selectTableItems({
    modelId: customerModel.modelId,
    multiple: false,
    defaultSelectType: 'empty',
    preSelectList: [],
    title: '选择客户',
    filterQuery: ''
  })

  if (!selectedIds || selectedIds.length === 0) return

  const customer = await getTableData(customerModel.modelId, selectedIds[0])

  console.log('客户详情:', customer)
}

main()

10. 调用子表映射弹窗选择 ​

10.1 使用 doPopupSelectAndMapping ​

此函数可以调用子表字段上预定义的“表单弹框选择数据复制”功能。

javascript
function main() {
  const mainModel = getModel('mainTable')
  const productModel = getModel('product')

  doPopupSelectAndMapping({
    childFieldId: mainModel.productChildTable,
    modelId: productModel.modelId,
    title: '选择产品',
    filterQuery: '?' + productModel.status + '=启用'
  })
}

main()

10.2 适用条件 ​

需要提前在子表字段上配置好：

  • 子表字段
  • 弹窗表单
  • 字段映射关系
  • 可选过滤条件

用户在弹窗中选择数据后，系统会根据映射关系把选择的数据复制到子表中。

10.3 和 selectTableItems 的区别 ​

函数用途
selectTableItems只负责弹窗选择，返回数据 ID 数组
doPopupSelectAndMapping弹窗选择后，按子表映射配置自动插入或复制数据

如果只是要拿 ID 自己处理，用 selectTableItems。
如果已经配置了子表映射，想让平台自动插入子表，用 doPopupSelectAndMapping。

11. 获取外键数据详情 ​

11.1 使用 getFkDataItem ​

给定主表外键字段 ID 和外键字段值，返回这条外表数据的完整对象。

javascript
async function main() {
  const orderModel = getModel('order')

  const fkFieldId = orderModel.customer
  const fkValue = recordData[orderModel.customer]

  if (!fkValue) return

  const customer = await getFkDataItem(fkFieldId, fkValue)

  console.log('客户详情:', customer)
}

main()

注意：

  • 第一个参数是主表中的外键字段 ID。
  • 第二个参数是外键字段值，通常是外表数据 ID。

11.2 表单校验中使用 ​

javascript
async function main() {
  const orderModel = getModel('order')
  const customerModel = getModel('customer')

  const fkValue = recordData[orderModel.customer]

  if (!fkValue) {
    return [false, '请选择客户']
  }

  const customer = await getFkDataItem(orderModel.customer, fkValue)

  if (customer && customer[customerModel.creditLevel] === '低') {
    return [false, '客户信用等级过低，不能提交']
  }

  return [true, '']
}

return main()

12. 子表字段显示隐藏和只读控制 ​

虽然这不是外键过滤，但经常和子表选择、子表映射一起出现。

12.1 隐藏子表字段 ​

javascript
setChildFieldsAttr(childField, subChildField, 'show', false)

参数：

  • childField：主表中的子表字段 ID。
  • subChildField：子表中的字段 ID。
  • 'show'：控制显示隐藏。
  • false：隐藏。

12.2 设置子表字段只读 ​

javascript
setChildFieldsAttr(childField, subChildField, 'editable', false)

12.3 控制多个字段 ​

javascript
setChildFieldsAttr(childField, [subInput, subNumber, subSelect, subDate], 'show', false)

12.4 控制所有字段 ​

javascript
setChildFieldsAttr(childField, 'all', 'show', false)

12.5 根据主表字段动态控制 ​

javascript
function main() {
  if (recordData[eventFieldId] === '1') {
    setChildFieldsAttr(childField, [subInput, subNumber, subSelect, subDate], 'show', true)
  } else {
    setChildFieldsAttr(childField, [subInput, subNumber, subSelect, subDate], 'show', false)
  }
}

main()

13. 常见坑 ​

13.1 setFkFieldFilter 没生效 ​

排查：

  • 插件场景是否是表单编辑。
  • 事件是否是字段初始化、字段值变化或按钮点击。
  • fkFieldId 是否是主表中的外键字段 ID。
  • 子表行内过滤是否传了第三个参数 recordData。
  • 查询字符串是否以 ? 开头。
  • 查询字段是否是外表字段 ID，而不是主表字段 ID。

13.2 快速过滤外键下拉没有过滤 ​

排查：

  • 是否使用了 setQuickFilterFkFilter，而不是 setFkFieldFilter。
  • 插件是否绑定在表格详情的页面初始化事件。
  • fkFieldId 是否是当前表单上的快速过滤外键字段。
  • queryStr 是针对外表的过滤条件。

13.3 getFkOptions 返回空 ​

排查：

  • 外表 modelId 是否正确。
  • 查询字段 ID 是否属于外表。
  • 查询条件是否过严。
  • 外表是否有符合条件的数据。
  • 程序标识是否配置正确。

13.4 弹窗选择后没有插入子表 ​

如果用的是 doPopupSelectAndMapping：

  • 检查子表字段 ID 是否正确。
  • 检查弹窗表单 ID 是否正确。
  • 检查子表映射关系是否已配置。
  • 检查过滤条件是否导致没有可选数据。

如果只是用 selectTableItems：

  • 它只返回 ID，不会自动插入子表，需要自己写插入逻辑。

13.5 ? 和 & 用错 ​

一般规则：

  • 独立 query 从 ? 开始。
  • 拼到已有 query 后面用 &。

例如：

javascript
const query1 = '?' + fieldA + '=1'
const query2 = query1 + '&' + fieldB + '=2'

16. 推荐实践 ​

  1. 外键过滤先确认场景，再选函数。
  2. 表单编辑外键用 setFkFieldFilter。
  3. 表格快速过滤外键用 setQuickFilterFkFilter。
  4. 子表行内外键过滤记得传第三个参数 recordData。
  5. 查询条件里的字段 ID 应该属于被过滤的外表。
  6. 弹窗只拿 ID 用 selectTableItems。
  7. 弹窗后自动插子表用 doPopupSelectAndMapping。
  8. tableSearch 外键下拉过滤在字段配置里写 attrs.filter。
  9. 组件绑定 Table 后，设置过滤还要刷新。
  10. 遇到不生效，第一步打印模型、字段 ID、query 字符串。
