13-接口请求与第三方系统对接操作说明 ​

适用对象：闪用前端插件调用第三方接口、带登录态调用平台接口、调用中台 API、调用后端插件、业务中台读取请求用户、WebSocket API、IoT 设备接口。

本篇基于在线文档中明确出现的 request、requestWithToken、webhookApi、invokeBackPlugin、SystemJS.import、invokeIotDeviceApi、crws、authenticate/request user 等内容整理。

1. 接口能力速查 ​

常用接口能力：

  • request({ url, method, headers, data })

    • 前端插件调用第三方 API。

  • requestWithToken({ url, method, headers, data })

    • 前端插件带已有 token 调用接口。

  • webhookApi(url, method, data, headers)

    • 前端插件调用闪搭中台 API。

  • invokeBackPlugin(pluginID, params)

    • 前端插件调用后端插件并拿返回值。

  • SystemJS.import(url)

    • 动态引入外部 JS 或 CSS 模块。

  • invokeIotDeviceApi({ action, device })

    • 获取特定 IoT 设备或设备点位数据。

  • crws

    • 中台 WebSocket 模块，用于注册 WebSocket API。

2. request 调第三方 API ​

文档说明：request 可以调用第三方 API 接口。

函数形式：

javascript
request({ url, method, headers, data })

参数：

  • url：接口地址。
  • method：请求方法。
  • headers：请求头对象。
  • data：请求体对象，可选。

示例：

javascript
async function main() {
  const url = 'https://example.com/api/search'
  const headers = {
    contentType: 'application/json'
  }
  const data = {
    query: 'emit'
  }

  const response = await request({
    url,
    method: 'GET',
    headers,
    data
  })

  console.log('接口返回：', response)
}

main()

3. requestWithToken 调带登录态接口 ​

文档说明：requestWithToken 可以带着已有 token 调用接口。

函数形式：

javascript
requestWithToken({ url, method, headers, data })

文档示例是修改密码接口：

javascript
await requestWithToken({
  url: 'https://login.yundanyun.com/api/users/selfUserProfile/urprf_demo/changePassword/',
  method: 'patch',
  data: {
    password: '111111'
  }
})

整理成通用写法：

javascript
async function main() {
  showLoading('处理中...')

  try {
    const resp = await requestWithToken({
      url: `${window.location.origin}/app/api/demo/`,
      method: 'post',
      headers: {
        contentType: 'application/json'
      },
      data: {
        id: recordData.id
      }
    })

    console.log('返回结果：', resp)
    Message.success('操作成功')
  } catch (err) {
    console.log(err)
    MessageBox.alert(`接口调用失败：${err}`, '错误', { type: 'error' })
  }

  clearLoading()
}

main()

注意：

  • 需要用户登录态的内部接口优先用 requestWithToken。
  • 不需要平台 token 的第三方公开接口可用 request。
  • 返回结构以实际 console.log(resp) 为准。

4. webhookApi 调中台 API ​

文档说明：webhookApi 用于调用闪搭中台 API。

函数形式：

javascript
webhookApi(url, method, data, headers)

参数：

  • url：中台 API 路径。
  • method：请求方法，可选 post、get、put、patch、delete，默认 get。
  • data：请求体对象。
  • headers：请求头对象。

文档示例：

javascript
const queryData = {
  groupType: 'deviceState'
}

const resp = await webhookApi('/getDeviceStat', 'post', queryData)

整理成通用写法：

javascript
async function main() {
  const data = {
    groupType: 'deviceState'
  }

  const resp = await webhookApi('/getDeviceStat', 'post', data)
  console.log('中台 API 返回：', resp)
}

main()

5. invokeBackPlugin 调后端插件 ​

文档说明：invokeBackPlugin 可以调用后端插件并拿到返回结果。

函数形式：

javascript
invokeBackPlugin(pluginID, params)

参数：

  • pluginID：后端插件 id。
  • params：插件参数对象。

文档示例结构：

javascript
const pluginID = 'ingin_demo'
const params = {
  xplugin_func: 'create_missions',
  xplugin_data: {
    object_pk: recordData.id,
    app: 'ncapp_demo',
    model: 'ncmod_demo'
  }
}

let resp = await invokeBackPlugin(pluginID, params)

整理成通用模板：

javascript
async function main() {
  showLoading('处理中...')

  try {
    const resp = await invokeBackPlugin('ingin_demo', {
      xplugin_func: 'run',
      xplugin_data: {
        id: recordData.id
      }
    })

    console.log('后端插件返回：', resp)
    Message.success('调用成功')
  } catch (err) {
    console.log(err)
    MessageBox.alert(`后端插件调用失败：${err}`, '错误', { type: 'error' })
  }

  clearLoading()
}

main()

6. SystemJS.import 动态引入模块 ​

文档说明：SystemJS.import(url) 可动态引入外部模块，例如 JS 模块、CSS 模块。

6.1 引入 JS ​

javascript
async function main() {
  await SystemJS.import('/webapp/static/swiper-bundle.min.js')

  const mySwiper = new Swiper('.swiper-container', {
    navigation: {
      nextEl: '.swiper-button-next',
      prevEl: '.swiper-button-prev'
    },
    pagination: {
      el: '.swiper-pagination'
    }
  })

  console.log(mySwiper)
}

main()

6.2 引入 CSS ​

文档示例：

javascript
const moduleCSS = await SystemJS.import('/webapp/static/swiper-bundle.min.css')
const styleSheet = moduleCSS.default
document.adoptedStyleSheets = [...document.adoptedStyleSheets, styleSheet]

也可以使用文档里的 importCss：

javascript
importCss('/webapp/static/index.css')

7. 获取 IoT 设备数据 ​

文档里有两类相关能力。

7.1 invokeIotDeviceApi ​

函数形式：

javascript
invokeIotDeviceApi({ action, device })

参数：

  • action：get_device 或 get_device_data。
  • device：物联网设备 id。

示例：

javascript
async function main() {
  const deviceId = 'device_demo'
  const deviceInfoList = await invokeIotDeviceApi({
    action: 'get_device_data',
    device: deviceId
  })

  console.log('设备数据：', deviceInfoList)
}

main()

7.2 设备信息 API ​

文档中的设备信息接口：

  • 地址：/api/device/device/
  • 请求方式：GET
  • 请求头：Authorization 必填。

返回字段包含：

  • msg
  • code
  • count
  • total_count

8. 业务中台获取请求用户 ​

文档说明：在业务中台使用 httpin 节点，并打开 Auth 验证，可以从请求里获取用户信息。

示例：

javascript
const request = msg.req
node.error(msg.req.user)

中台文档还提到：

javascript
authenticate(request)
getRequestUser(request)

说明：

  • authenticate(request) 对当前 HTTP request 做 token 验证，并记录当前用户到 request。
  • getRequestUser(request) 获取当前 request user。

9. 中台接口解析查询参数 ​

中台文档里提到：

javascript
const filterQuery = await parseQuery(app, model, request)

作用：

  • 基于当前 request URL 解析过滤条件。
  • 支持解析 page、page_size、order、search 等。

文档示例里也用到了：

javascript
const filterQuery = await crmodel.parseQuery(modelInfo.appName, modelInfo.modelName, msg.req)
const data = await crmodel.findAndCountAll(modelInfo.appName, modelInfo.modelName, filterQuery)

10. WebSocket API ​

文档里的 crws 模块用于 WebSocket 服务初始化和管理。

10.1 引入模块 ​

javascript
const crws = global.get('crws')

10.2 初始化 ​

javascript
const crws = global.get('crws')
crws.init(app, server)

10.3 获取对象 ​

javascript
const app = crws.getApp()
const httpServer = crws.getHttpServer()
const webSocket = crws.getWebSocket()

10.4 注册 WebSocket API ​

javascript
const crws = global.get('crws')

const api = 'example'
const handlers = {
  openHandler: ws => {
    console.log(`${api} connected.`)
  },
  closeHandler: ws => {
    console.log(`${api} disconnected.`)
  },
  messageHandler: (ws, data) => {
    console.log(`${api} received message: ${data}`)
  },
  errorHandler: (ws, err) => {
    console.error(`${api} error: ${err}.`)
  }
}

crws.registerWsApi(api, handlers)

11. 接口请求推荐模板 ​

这部分是基于文档 API 的整理模板。

javascript
async function main() {
  showLoading('加载中...')

  try {
    const resp = await requestWithToken({
      url: `${window.location.origin}/app/api/demo/`,
      method: 'post',
      headers: {
        contentType: 'application/json'
      },
      data: {
        id: recordData.id
      }
    })

    console.log('resp', resp)
    Message.success('操作成功')
  } catch (err) {
    console.log(err)
    MessageBox.alert(`操作失败：${err}`, '错误', { type: 'error' })
  }

  clearLoading()
}

main()

12. 常见坑 ​

  • request 和 requestWithToken 混用：需要平台登录态的接口优先用 requestWithToken。
  • 没有打印返回值：不同接口返回结构不同，先 console.log(resp)。
  • 忘记 await：接口调用后要等待返回再刷新或跳转。
  • 加载状态没有关闭：用了 showLoading 后，异常分支也要 clearLoading。
  • 中台接口没有验证 token：需要用户信息时，httpin 节点要打开 Auth 验证。
  • WebSocket handler 里没有错误处理：至少保留 errorHandler 打印错误。
