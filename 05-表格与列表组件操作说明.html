05-表格与列表组件操作说明 ​

适用对象：高级表格、行内编辑表格、表单列表、手机端 List 组件。

这篇主要解决日常开发里最常遇到的几类问题：动态设置列、设置数据、获取选中行、行内按钮传参、批量处理、刷新表格、过滤绑定表数据、分页加载 List。

1. 先分清四类对象 ​

表格相关问题最容易卡在“名字看起来都像表格”，实际却不是一类东西。

  • 高级表格组件

    • 常见组件名：crCusTable_xxx
    • 主要通过 attrs.attrs.* 设置列、数据、选中行、分页、行内按钮等。
    • 适合自定义展示、自定义按钮、自定义数据源。

  • 行内编辑表格组件

    • 常见组件名：crInlineEditTable_xxx
    • 主要通过 getElemInstance 获取实例。
    • 适合在表格内直接编辑、添加行、删除行、提交整表数据。

  • 表单列表 / Table 资源

    • 常见资源名：TBL_xxx
    • 这是表单绑定出来的列表资源，不一定等于页面上的组件名。
    • 常用 setTableFilter、refreshTableData 控制过滤和刷新。

  • 手机端 List 组件

    • 常见组件名：list_xxx
    • 主要通过 attrs.attrs.getPageData 挂载分页请求函数。
    • 下拉刷新、滚动加载、加载状态通常由组件内部封装。

2. 高级表格常用属性 ​

高级表格大部分操作都围绕 attrs.attrs 这一层。

常用属性如下：

  • attrs.attrs.cols：列配置。
  • attrs.attrs.data：表格数据。
  • attrs.attrs.selectedRows：当前勾选的数据行。
  • attrs.attrs.rowButtons：行内按钮配置。
  • attrs.attrs.clickedRow：当前点击行。
  • attrs.attrs.clickedCell：当前点击单元格值。
  • attrs.attrs.checkedIds：勾选行 id 集合，常用于重置勾选。
  • attrs.attrs.showSelection：是否显示勾选栏。
  • attrs.attrs.showIndex：是否显示序号栏。
  • attrs.attrs.fixedColumnNum：从左侧开始冻结的列数。
  • attrs.attrs.currentPage：当前页码。
  • attrs.attrs.pageSize：每页数量。
  • attrs.attrs.total：总条数。
  • attrs.attrs.loading：是否显示加载状态。
  • attrs.attrs.loadingText：加载文案。

推荐统一使用 setValueByName 写入，这样组件名和属性路径更清楚。

javascript
setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.data',
  value: []
})

如果项目里已经习惯使用 g.e，也可以直接写：

javascript
g.e.crCusTable_demo.set.attrs.attrs.data = []

3. 动态设置表格列 ​

3.1 基础列配置 ​

列配置写入 attrs.attrs.cols。

javascript
const cols = [
  {
    label: '物料编号',
    prop: 'skuNo',
    type: 'string',
    minWidth: '160px',
    align: 'center'
  },
  {
    label: '物料名称',
    prop: 'skuName',
    type: 'string',
    minWidth: '220px',
    align: 'left'
  },
  {
    label: '创建时间',
    prop: 'createTime',
    type: 'dateTime',
    minWidth: '170px'
  },
  {
    label: '是否有效',
    prop: 'isValid',
    type: 'switch',
    minWidth: '100px'
  }
]

setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.cols',
  value: cols
})

常用列字段：

  • label：列名。
  • prop：对应数据字段。
  • type：列类型，例如 string、image、file、switch、progress、dateTime、vhtml。
  • width：固定列宽。
  • minWidth：最小列宽。
  • align：对齐方式，可用 left、center、right。
  • children：分组列。

3.2 分组列 ​

列对象里使用 children 即可配置分组。

javascript
const cols = [
  {
    label: '基础信息',
    children: [
      { label: '物料编号', prop: 'skuNo', type: 'string', minWidth: '160px' },
      { label: '物料名称', prop: 'skuName', type: 'string', minWidth: '220px' }
    ]
  },
  {
    label: '状态信息',
    children: [
      { label: '创建时间', prop: 'createTime', type: 'dateTime', minWidth: '170px' },
      { label: '是否有效', prop: 'isValid', type: 'switch', minWidth: '100px' }
    ]
  }
]

setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.cols',
  value: cols
})

3.3 自定义 HTML 列 ​

需要一列展示多行内容、富文本标记、组合字段时，可以使用 vhtml。

javascript
const cols = [
  { label: '物料编号', prop: 'skuNo', type: 'string', minWidth: '150px' },
  { label: '物料名称', prop: 'skuName', type: 'string', minWidth: '180px' },
  { label: '描述', prop: 'descriptionHtml', type: 'vhtml', minWidth: '260px' }
]

const data = [
  {
    id: '1',
    skuNo: 'SKU-001',
    skuName: '物料 A',
    descriptionHtml: '<p><strong>规格：</strong>大号</p><p><strong>颜色：</strong>蓝色</p>'
  }
]

setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.cols', value: cols })
setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.data', value: data })

注意：

  • vhtml 的内容来自用户输入时，要注意 XSS 风险。
  • 如果只是普通文本拼接，优先使用普通 string 列。
  • HTML 字符串不要拼接不可信脚本。

3.4 冻结列 ​

横向列很多时，可以冻结左侧前几列。

javascript
setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.fixedColumnNum',
  value: 1
})

fixedColumnNum = 1 表示冻结第一列。

  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.data',
  value: data

4.2 从接口查询后设置数据 ​

javascript
async function main() {
  const productModel = getModel('product')
  const res = await invokeModelApi(productModel.modelId, 'getList', 0, 0, '?page=1&page_size=20')

  const rows = res.data?.results?.data || res.data?.data || []
  const total = res.data?.total_count || rows.length

  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.data', value: rows })
  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.total', value: total })
}

main()

实际项目里不同接口返回结构可能不同，先 console.log(res) 看清楚再取值。

5. 获取当前点击行或单元格 ​

高级表格事件参数通常通过 eventArgs 获取。

5.1 点击行 ​

表格事件：click-row

回调参数：{ row }

javascript
function main() {
  const row = eventArgs.row
  console.log('当前点击行：', row)

  if (!row || !row.id) {
    Message.warning('未获取到当前行数据')
    return
  }

  setValueByName({
    name: 'VAR_currentRowId',
    type: 'var',
    value: row.id
  })
}

main()

5.2 点击单元格 ​

表格事件：click-cell

回调参数：{ row, column }

javascript
function main() {
  const row = eventArgs.row
  const column = eventArgs.column

  console.log('当前行：', row)
  console.log('当前列：', column)
}

6. 行内按钮传参 ​

这是表格开发里最常用的场景。

6.1 配置行内按钮 ​

行内按钮写入 attrs.attrs.rowButtons。

javascript
const rowButtons = [
  { label: '查看' },
  { label: '编辑' },
  { label: '删除' }
]

setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.rowButtons',
  value: rowButtons
})

6.2 在按钮事件里拿当前行 ​

表格事件：row-button-click

回调参数：{ button, row, rowIndex }

javascript
async function main() {
  const button = eventArgs.button
  const row = eventArgs.row
  const rowIndex = eventArgs.rowIndex

  console.log('点击按钮：', button)
  console.log('当前行：', row)
  console.log('当前行索引：', rowIndex)

  if (!row || !row.id) {
    Message.error('当前行缺少 id，无法继续操作')
    return
  }

  if (button.label === '删除') {
    await deleteCurrentRow(row)
  }
}

async function deleteCurrentRow(row) {
  const ok = await MessageBox.confirm('确认删除当前行？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(() => true).catch(() => false)

  if (!ok) {
    return
  }

  const productModel = getModel('product')
  await invokeModelApi(productModel.modelId, 'delete', row.id, {}, 0)

  Message.success('删除成功')
  refreshTable()
}

main()

结论很简单：

  • 当前按钮：eventArgs.button
  • 当前行：eventArgs.row
  • 当前行索引：eventArgs.rowIndex
  • 当前行 id：通常是 eventArgs.row.id

6.3 根据当前行禁用按钮 ​

按钮对象可以配置 disable 函数，函数参数就是当前行 row。

javascript
function disableDelete(row) {
  // true 表示禁用，false 表示不禁用
  return row.status === '已审核'
}

const rowButtons = [
  { label: '编辑' },
  { label: '删除', disable: disableDelete }
]

setValueByName({
  name: 'crCusTable_demo',
  type: 'elem',
  attr: 'attrs.attrs.rowButtons',
  value: rowButtons
})

6.4 在表格详情里控制按钮显隐或置灰 ​

如果是表格详情场景，可在行初始化事件里使用 setButtonAttr。

javascript
function main() {
  const id = recordData.id

  if (recordData.status === '已审核') {
    setButtonAttr('编辑', 'disable', true, id)
    setButtonAttr('删除', 'show', false, id)
    return
  }

  setButtonAttr('编辑', 'disable', false, id)
  setButtonAttr('删除', 'show', true, id)
}

main()

setButtonAttr 参数：

  • 第 1 个参数：按钮名称，支持字符串或字符串数组。
  • 第 2 个参数：属性名，常用 show 或 disable。
  • 第 3 个参数：属性值。
  • 第 4 个参数：当前数据 id。

7. 获取选中行 ​

7.1 从高级表格组件属性获取 ​

javascript
function getSelectedRows() {
  const rows = getValueByName({
    name: 'crCusTable_demo',
    type: 'elem',
    attr: 'attrs.attrs.selectedRows'
  }) || []

  if (!rows.length) {
    Message.warning('请至少选择一条数据')
    return []
  }

  return rows
}

7.2 从表单列表插件参数获取 ​

在某些表单列表按钮插件里，选中行会通过 recordSelections 传入。

javascript
function main() {
  if (!recordSelections || recordSelections.length === 0) {
    Message.warning('请先选择数据')
    return
  }

  console.log('选中的记录：', recordSelections)
}

main()

7.3 批量删除选中行 ​

javascript
async function main() {
  const rows = getValueByName({
    name: 'crCusTable_demo',
    type: 'elem',
    attr: 'attrs.attrs.selectedRows'
  }) || []

  if (!rows.length) {
    Message.warning('请选择需要删除的数据')
    return
  }

  const ok = await MessageBox.confirm(`确认删除 ${rows.length} 条数据？`, '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(() => true).catch(() => false)

  if (!ok) {
    return
  }

  const productModel = getModel('product')

  for (const row of rows) {
    await invokeModelApi(productModel.modelId, 'delete', row.id, {}, 0)
  }

  Message.success('删除成功')
  refreshTable()
}

main()

注意这里使用 for...of，不要用 forEach(async () => {}) 做需要等待结果的批量操作。

7.4 批量修改选中行 ​

javascript
async function main() {
  if (!recordSelections || recordSelections.length === 0) {
    Message.warning('请先选择数据')
    return
  }

  const productModel = getModel('product')

  for (const row of recordSelections) {
    const data = {
      [productModel.status]: '已处理'
    }

    await invokeModelApi(productModel.modelId, 'update', row.id, data, 0)
  }

  Message.success('批量修改成功')
  refreshTable()
}

main()

9. 过滤绑定数据表后的列表 ​

当组件或页面绑定的是 Table 资源时，推荐用 setTableFilter 设置过滤，再用 refreshTableData 刷新。

javascript
const tablename = 'TBL_product'

async function main() {
  const productModel = getModel('product')
  const queryString = `${productModel.status}=启用`

  setTableFilter({
    tablename,
    queryString
  })

  await refreshTableData({
    tablename
  })
}

main()

注意：

  • tablename 是资源库里的 Table 名称，不一定是页面组件名。
  • queryString 写字段过滤条件，不要把组件名写进去。
  • 设置过滤后要刷新，否则页面可能仍显示旧数据。

11. 高级表格分页 ​

高级表格分页常用属性：

  • attrs.attrs.enablePager：是否开启分页。
  • attrs.attrs.currentPage：当前页码。
  • attrs.attrs.pageSize：每页数量。
  • attrs.attrs.total：总条数。
  • attrs.attrs.pagerSizes：可选分页大小。
  • attrs.attrs.pagerLayout：分页器布局。

11.1 加载指定页数据 ​

javascript
async function loadTableData(page, pageSize) {
  const productModel = getModel('product')
  const query = `?page=${page}&page_size=${pageSize}`
  const res = await invokeModelApi(productModel.modelId, 'getList', 0, 0, query)

  const rows = res.data?.results?.data || []
  const total = res.data?.total_count || 0

  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.data', value: rows })
  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.currentPage', value: page })
  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.pageSize', value: pageSize })
  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.total', value: total })
}

11.2 响应分页变化 ​

表格事件：page-change

回调参数：{ val }

不同版本里 val 可能包含页码、页容量等信息，建议先打印确认结构。

javascript
async function main() {
  console.log('分页事件参数：', eventArgs)

  const val = eventArgs.val || {}
  const page = val.currentPage || val.page || 1
  const pageSize = val.pageSize || val.size || 10

  await loadTableData(page, pageSize)
}

main()

12. 表格排序 ​

表格事件：sort-change

回调参数：{ sortList }

javascript
async function main() {
  const sortList = eventArgs.sortList || []
  console.log('排序条件：', sortList)

  const firstSort = sortList[0]
  if (!firstSort) {
    return
  }

  const field = firstSort.field || firstSort.property
  const order = firstSort.order

  await reloadBySort(field, order)
}

async function reloadBySort(field, order) {
  const productModel = getModel('product')
  const query = `?ordering=${order === 'desc' ? '-' : ''}${field}`
  const res = await invokeModelApi(productModel.modelId, 'getList', 0, 0, query)

  const rows = res.data?.results?.data || []
  setValueByName({ name: 'crCusTable_demo', type: 'elem', attr: 'attrs.attrs.data', value: rows })
}

main()

排序参数不同版本可能略有差异，首次接入时一定先 console.log(eventArgs)。

13. 表格拖拽排序 ​

开启拖拽后，拖拽结束会触发 row-moved。

事件参数：{ oldIndex, newIndex, prevRow, row }

javascript
async function main() {
  const { oldIndex, newIndex, prevRow, row } = eventArgs

  console.log('旧位置：', oldIndex)
  console.log('新位置：', newIndex)
  console.log('被拖拽行：', row)
  console.log('前一行：', prevRow)

  if (!row || !row.id) {
    return
  }

  await saveSort(row, newIndex, prevRow)
}

async function saveSort(row, newIndex, prevRow) {
  const productModel = getModel('product')

  await invokeModelApi(productModel.modelId, 'update', row.id, {
    [productModel.sortNo]: newIndex + 1,
    prevId: prevRow ? prevRow.id : ''
  }, 0)

  Message.success('排序已保存')
}

main()

14. 行内编辑表格 ​

行内编辑表格通常通过实例方法操作。

14.1 获取实例 ​

javascript
const inlineTable = getElemInstance('crInlineEditTable_inline')

常用方法：

  • createRow(index, initData)：插入行。
  • deleteRow(row)：删除行。
  • getTableData()：获取当前表格数据。

14.2 新增一行 ​

javascript
function main() {
  const inlineTable = getElemInstance('crInlineEditTable_inline')

  const initData = {
    textCol1: '',
    numberCol: 0,
    switchCol: false
  }

  inlineTable.createRow(-2, initData)
}

main()

-2 常用于追加到表格末尾。

14.3 删除选中行 ​

javascript
async function main() {
  const inlineTable = getElemInstance('crInlineEditTable_inline')
  const selectedRows = inlineTable.attrs.selectedRows || []

  if (!selectedRows.length) {
    Message.warning('请选择需要删除的数据')
    return
  }

  const ok = await MessageBox.confirm('确认删除选中行？', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  }).then(() => true).catch(() => false)

  if (!ok) {
    return
  }

  for (const row of selectedRows) {
    inlineTable.deleteRow(row)
  }

  Message.success('已删除')
}

main()

14.4 获取编辑后的整表数据 ​

javascript
function main() {
  const inlineTable = getElemInstance('crInlineEditTable_inline')

  console.log('编辑后的表格数据：', tableData)
}

16. 手机端 List 组件 ​

手机端 List 的核心是给组件传入 getPageData 函数。

16.1 基础流程 ​

  1. List 组件绑定变量，例如 VAR_dataList。
  2. 在页面初始化插件里定义 getPageData。
  3. 把 getPageData 写入 List 组件的 attrs.attrs.getPageData。
  4. 清空绑定变量，触发组件重新加载。

16.2 挂载分页函数 ​

javascript
async function getPageData(page = 1, pageSize = 10) {
  const productModel = getModel('product')
  const query = `?page=${page}&page_size=${pageSize}`
  const res = await invokeModelApi(productModel.modelId, 'getList', 0, 0, query)

  const data = res.data?.results?.data || []
  const total = res.data?.total_count || 0

  const mappedData = data.map(item => {
    return {
      ...item,
      title: item[productModel.name],
      subTitle: item[productModel.code]
    }
  })

  return {
    data: mappedData,
    total
  }
}

function setPageData() {
  setValueByName({
    name: 'list_data',
    type: 'elem',
    attr: 'attrs.attrs.getPageData',
    value: getPageData
  })

  setValueByName({
    name: 'VAR_dataList',
    type: 'var',
    value: []
  })
}

setPageData()

16.3 新增、删除、修改后刷新 List ​

如果 List 绑定了变量，数据变更成功后可以把变量重新置为空数组，让组件重新取数。

javascript
async function main() {
  const productModel = getModel('product')

  await invokeModelApi(productModel.modelId, 'update', recordData.id, {
    [productModel.status]: '已完成'
  }, 0)

  setValueByName({
    name: 'VAR_dataList',
    type: 'var',
    value: []
  })

  Message.success('更新成功')
}

main()

List 组件内部通常已经封装了下拉刷新、加载中、滚动懒加载等行为；业务插件重点写好 getPageData 的请求和返回结构即可。

17. 表单列表配置要点 ​

表单列表更多是后台配置和前端按钮配合使用。

常用配置项：

  • 快速查询字段：前端出现固定查询条件，多个条件通常按 and 关系过滤。
  • 可搜索字段：前端搜索框能检索哪些字段。
  • 显示字段：列表里展示哪些字段，以及列宽、顺序、对齐方式。
  • 行内操作按钮：配置编辑、复制、调用插件、关联表操作等。
  • 功能按钮：搜索、添加、删除、编辑、打印、导入、导出、刷新、审核、反审等。
  • 每页默认数据条数：控制默认分页数量。
  • 分页栏显示位置：上方、下方或上下都显示。
  • 默认排序方法：按索引字段升序或降序。
  • 是否显示选择列 / 序号列 / 审核列：影响批量操作和用户识别数据。

行内操作按钮如果选择“调用 JS 插件”，插件里通常可以通过当前记录上下文拿到 recordData，通过选中记录拿到 recordSelections。

18. 常用事件速查 ​

高级表格常见事件：

  • click-row：点击行，参数 { row }。
  • click-cell：点击单元格，参数 { row, column }。
  • dblclick-row：双击行，参数 { row }。
  • dblclick-cell：双击单元格，参数 { row, column }。
  • select-change：勾选变化，参数 { selections, reserves, checked, row }。
  • row-button-click：点击行内按钮，参数 { button, row, rowIndex }。
  • toolbar-button-click：点击顶部工具栏左侧按钮，参数 { button }。
  • toolbar-tool-click：点击顶部工具栏右侧图标，参数 { button }。
  • page-change：分页变化，参数 { val }。
  • edit-change：编辑态单元格变化，参数 { row, col }。
  • sort-change：排序变化，参数 { sortList }。
  • row-moved：拖拽行后触发，参数 { oldIndex, newIndex, prevRow, row }。

20. 常见坑 ​

20.1 组件名和 Table 资源名混用 ​

错误倾向：

javascript
await refreshTableData({ tablename: 'crCusTable_demo' })

如果 crCusTable_demo 是组件名，而不是资源库 Table 名称，刷新不会按预期工作。

正确思路：

  • 操作高级表格组件属性：用组件名 crCusTable_xxx。
  • 刷新绑定表数据：用 Table 资源名 TBL_xxx。

20.2 设置过滤后忘记刷新 ​

javascript
setTableFilter({ tablename, queryString })
await refreshTableData({ tablename })

两步都要做。

20.3 行内按钮事件里没有看 eventArgs ​

行内按钮当前行不是靠全局变量猜出来的，而是从事件参数取：

javascript
const row = eventArgs.row
const button = eventArgs.button

20.4 当前行没有 id ​

删除、修改、跳转详情通常都需要 row.id。

如果表格数据是自己拼出来的，务必保留原始 id。

javascript
const mappedRows = rows.map(row => {
  return {
    id: row.id,
    name: row[model.name],
    status: row[model.status]
  }
})

20.5 forEach(async () => {}) 导致刷新过早 ​

不要这样写：

javascript
rows.forEach(async row => {
  await invokeModelApi(model.modelId, 'delete', row.id, {}, 0)
})

refreshTable()

推荐：

javascript
for (const row of rows) {
  await invokeModelApi(model.modelId, 'delete', row.id, {}, 0)
}

refreshTable()

20.6 List 返回结构不对 ​

getPageData 推荐返回：

javascript
return {
  data,
  total
}

如果只返回数组，组件可能不知道总数，滚动加载和分页状态容易异常。

22. 排查顺序 ​

表格或 List 不符合预期时，按这个顺序排查：

  1. 打印事件参数：console.log(eventArgs)。
  2. 确认当前行是否存在：eventArgs.row 或 recordData。
  3. 确认当前行是否有 id。
  4. 确认组件名是否正确：crCusTable_xxx、list_xxx、crInlineEditTable_xxx。
  5. 确认 Table 资源名是否正确：TBL_xxx。
  6. 确认数据写入路径是否正确：attrs.attrs.data、attrs.attrs.cols。
  7. 确认过滤后是否调用了刷新。
  8. 确认异步循环是否使用了 for...of。
  9. 确认接口返回结构，再决定取 res.data.results.data 还是其他路径。
