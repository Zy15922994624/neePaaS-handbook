15-移动端开发操作说明 ​

适用对象：手机 App 内嵌闪用页面、UniApp WebView、移动端 List、Vant Toast/Dialog/Notify/ImagePreview、移动端弹窗滚动、扫码组件。

本篇基于在线文档中明确出现的 UniApp WebView、SystemJS.import('/webapp/static/uni.webview.1.5.2.js')、uni.reLaunch、uni.navigateTo、uni.postMessage、Toast、Dialog、Notify、ImagePreview、手机端 List 等内容整理。

1. 手机 App 整体结构 ​

在线文档说明：

  • 手机 App 采用 UniApp 开发框架。
  • 通常登录页采用 UniApp 原生开发。
  • 登录之后跳转到闪用页面。
  • 闪用页面通过 UniApp 的 WebView 组件嵌套。
  • 之后主要应用页面可以在闪用里开发。

结构可以理解为：

text
UniApp 原生登录页 -> UniApp WebView 页面 -> WebView 内嵌闪用页面

2. 登录页跳转到闪用 WebView ​

文档建议从 UniApp 原生登录页跳转到 WebView 嵌套闪用页面时使用 uni.reLaunch。

原因：

  • reLaunch 会关闭当前页面后再跳转。
  • 手势返回时不会回到登录页。

示例：

javascript
uni.reLaunch({
  url: `/pages/tabPages/home/home?goto=home&ts=${this.timestamp}`
})

3. 闪用页面退出登录回 UniApp 登录页 ​

在线文档步骤：

  1. 引入 uni.webview.1.5.2.js。
  2. 弹出确认框。
  3. 确认后跳转到 deleteToken 页面。
javascript
async function main() {
  await SystemJS.import('/webapp/static/uni.webview.1.5.2.js')

  Dialog.confirm({
    title: '提示',
    message: '是否退出?'
  }).then(() => {
    Message({
      type: 'success',
      message: '退出成功!'
    })

    uni.navigateTo({
      url: '/pages/login/easyLogin/deleteToken'
    })
  }).catch(() => {
    Message({
      type: 'info',
      message: '已取消退出'
    })
  })
}

main()

4. 安卓手势返回处理 ​

在线文档说明：安卓 App 里，需要在 UniApp WebView 页面重写 onBackPress()，劫持系统默认手势返回。

基本逻辑：

  • 闪用页面处于根部时，手势返回交给 UniApp 处理。
  • 闪用页面不处于根部时，手势返回交给闪用页面内部处理。

5. UniApp 侧返回处理 ​

文档示例核心代码：

javascript
export default {
  onLoad(options) {
    var currentWebview = this.$scope.$getAppWebview()
    setTimeout(() => {
      this.webview = currentWebview.children()[0]
    }, 1000)
  },
  onBackPress(event) {
    if (!this.onRoot) {
      const obj = JSON.stringify({ msg: 'back' })
      try {
        const functionStr = `window.rcvUniappMsg(${obj})`
        this.webview.evalJS(functionStr)
      } catch (err) {
        console.log(err)
      }
    }

    return !this.onRoot
  },
  methods: {
    onRcvMsg(msg) {
      this.onRoot = msg.detail.data[0].onRoot
    }
  }
}

要点：

  • onBackPress 返回 true 时，不执行 UniApp 默认返回。
  • this.webview.evalJS 用来把返回事件传给闪用页面。
  • onRcvMsg 接收闪用页面传回来的根页面状态。

6. 闪用侧处理返回事件 ​

6.1 初始化 ​

文档示例：

javascript
async function rcvBackPress() {
  const curPageStacks = await storageApi.getItem('pageStacks')
  const lastPage = curPageStacks.pop()

  jumpToPage(lastPage)

  await storageApi.setItem('pageStacks', curPageStacks)

  if (curPageStacks.length === 0) {
    uni.postMessage({
      data: {
        onRoot: true
      }
    })
  }
}

async function readyCallback() {
  window.rcvUniappMsg = async msg => {
    await rcvBackPress()
  }
}

function plusReady(callback) {
  if (window.plus) {
    callback()
  } else {
    document.addEventListener('plusready', callback)
  }
}

async function sysInit() {
  await SystemJS.import('/webapp/static/uni.webview.1.5.2.js')
  await storageApi.setItem('pageStacks', [])
  plusReady(readyCallback)
}

sysInit()

6.2 常规页面跳转时维护栈 ​

文档示例表达的是：跳转时保存页面栈，并通知 UniApp 当前不在根页面。

javascript
async function jumpPage(pageName) {
  const curPageStacks = await storageApi.getItem('pageStacks')

  jumpToPage(pageName)
  curPageStacks.push(pageName)

  await storageApi.setItem('pageStacks', curPageStacks)

  uni.postMessage({
    data: {
      onRoot: false
    }
  })
}

7. 移动端 Toast ​

在线文档说明：

  • Toast(title)
  • Toast.success(title)
  • Toast.fail(title)
  • Toast.loading({ message, forbidClick })
  • Toast({ message, position })

7.1 普通提示 ​

javascript
Toast('操作成功')

7.2 失败提示 ​

javascript
Toast({
  message: '提交失败，请检查网络连接',
  icon: 'fail'
})

7.3 加载提示 ​

javascript
const toast = Toast.loading({
  duration: 0,
  forbidClick: true,
  message: '加载中...'
})

setTimeout(() => {
  toast.clear()
}, 3000)

常用参数：

  • message：文本内容。
  • duration：展示时长，值为 0 时不会自动消失。
  • position：展示位置，可选 top、middle、bottom。
  • forbidClick：是否禁止背景点击。
  • type：success、fail、loading、html。

11. 手机端 List 组件 ​

在线文档说明：List 组件通过 getPageData 获取数据，返回 data 和 total。

下拉刷新、加载中、滚动懒加载等行为已经封装在 List 组件的 getPageData 里。

javascript
async function getPageData() {
  let res = await invokeTableApi(
    app,
    dataModel.modelId,
    'getList',
    0,
    0,
    `?page=${page}&page_size=${pageSize}`
  )

  let data = res.data.results.data
  let total = res.data.total_count

  for (let item of data) {
    // 映射
  }

  return { data, total }
}

function setPageData() {
  setValueByName({
    name: 'list_data',
    type: 'elem',
    attr: 'attrs.attrs.getPageData',
    value: getPageData
  })

  setValueByName({
    name: 'VAR_dataList',
    type: 'var',
    value: []
  })
}

12. 移动端 popup 滚不动 ​

在线文档说明：闪用标签组件 mobile popup 模式下页面滚不动时，需要关闭“锁定背景滚动”开关。

处理方式：

  • 找到标签组件的“锁定背景滚动”。
  • 将开关关闭。

13. 绝对模式弹窗跟随页面大小 ​

在线文档说明：如果希望页面缩放时，弹窗中的内容一并缩放：

  1. 在外部组件处设置弹窗组件宽高为 100%。
  2. 在外部组件处关闭“弹框插入 Body”。
  3. 需要全屏效果时，设置“对话框距顶”为 0。

14. 扫码组件 ​

在线文档中扫码组件支持：

  • 扫码设备：扫码枪、摄像头。
  • 编码类型：目前仅限二维码。
  • 组件类型：
    • 更新数据。
    • 显示数据。
    • 远程插件。

14.1 更新数据 ​

用于扫码后更新表单数据。

配置步骤：

  1. 选择源数据表单。
  2. 选择目标数据表单。
  3. 选择操作类型：插入、更新、删除。

14.2 显示数据 ​

用于扫码后显示表单内容。

显示表单：

  • 任意表单。
  • 指定表单。

显示类型：

  • 显示数据详情。
  • 显示图片附件。

14.3 远程插件 ​

用于选择第三方插件，让扫码后逻辑更灵活。

注意：文档说明远程插件是前台的 API 接口组件，使用前必须有一个设置好的 API 接口组件文件。

15. 移动端兼容注意 ​

在线文档“闪用开发最佳实践”提到：

  • 可选链语法 ?. 在一些老安卓手机上不支持，不建议使用。
  • 可使用 utils.get(obj, attr, defaultValue) 替代。

示例：

javascript
const value = utils.get(data, 'attr1.attr2.0.attr3')

16. 常见坑 ​

  • 闪用退出登录前没有引入 UniApp SDK：先 SystemJS.import('/webapp/static/uni.webview.1.5.2.js')。
  • 安卓返回直接退出 App：UniApp 侧需要重写 onBackPress，闪用侧需要维护页面栈。
  • List 不刷新：重新设置绑定变量为空数组，触发重新加载。
  • 移动端 popup 滚动异常：关闭“锁定背景滚动”。
  • 老安卓语法兼容：避免使用可选链 ?.。
  • Toast 加载不消失：duration: 0 时需要手动 toast.clear()。
