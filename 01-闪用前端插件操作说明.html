01-闪用前端插件操作说明 ​

整理日期：2026-05-17
适用范围：neePaaS / 闪用页面 / 前端插件
目标：把闪用前端插件的日常开发能力整理成可查、可复制、可排错的操作说明。

1. 这篇解决什么问题 ​

闪用前端插件用于补充页面组件本身无法直接完成的逻辑，例如：

  • 点击按钮后处理变量或组件属性
  • 获取当前点击的组件、当前行、当前迭代器项
  • 查询、创建、更新、删除表单数据
  • 调用后端插件
  • 页面跳转和传参
  • 父子闪用页面通信
  • 弹窗确认、消息提示、加载中提示
  • 动态修改组件样式
  • 手机端调试

这篇先整理前端插件的“通用底座”。具体表单增删改查、外键过滤、表格组件、子表操作会单独成篇。

2. 前端插件里最重要的几个对象 ​

2.1 elem ​

elem 是当前触发插件的组件实例对象。

常用场景：

javascript
console.log('当前触发组件:', elem)

如果插件是在迭代器或 List 内部触发，当前项数据通常在：

javascript
const currentItem = elem.repeater.childData
const currentIndex = elem.repeater.childIndex

多个按钮共用一个插件时，可以通过 elem.suffix 区分按钮：

javascript
function main() {
  console.log('elem:', elem)

  switch (elem.suffix) {
    case 'edit':
      editItem()
      break
    case 'delete':
      deleteItem()
      break
    default:
      console.log('未匹配按钮:', elem.suffix)
  }
}

main()

2.2 event ​

event 是触发插件的事件名，例如：

  • click
  • dblclick
  • mousedown
  • mouseup
  • mouseover
  • mouseout
  • contextmenu

调试时可以打印：

javascript
console.log('事件名:', event)

2.3 eventArgs ​

eventArgs 是当前事件传递过来的参数对象。不同组件、不同事件的数据结构不同。

例如：

  • 高级表格行内按钮点击：通常能拿到按钮、行数据、行索引等信息。
  • 父页面接收子页面消息：通过 eventArgs 获取子页面传来的参数。
  • 闪用组件接收父页面参数：在 rcvParams 触发器里通过 eventArgs 获取参数。

通用调试写法：

javascript
console.log('eventArgs:', eventArgs)

不要一开始就猜结构，先打印出来看。

2.4 userId ​

userId 是当前登录用户的系统用户 ID。

javascript
console.log('当前用户ID:', userId)

如果需要获取更完整的用户信息，可以结合表单模型或系统用户接口查询，后续会单独整理。

3. 推荐插件结构 ​

建议每个插件都写成 main() 入口，复杂逻辑拆函数。

同步插件：

javascript
function main() {
  console.log('插件开始执行')
}

main()

异步插件：

javascript
async function main() {
  console.log('插件开始执行')
  const data = await getSomething()
  console.log('结果:', data)
}

main()

需要给平台返回结果时：

javascript
async function main() {
  const result = await getSomething()
  return result
}

return main()

比如某些“获取数据插件”要求返回数据 ID 或数据列表，就需要 return。

4. 调试方式 ​

4.1 基础打印 ​

javascript
console.log('elem:', elem)
console.log('event:', event)
console.log('eventArgs:', eventArgs)
console.log('userId:', userId)

4.2 使用 crLog ​

文档里提供了 crLog：

javascript
crLog.info('普通日志')
crLog.debug('调试日志')
crLog.warn('警告日志')
crLog.error('错误日志')

javascript

4.3 手机端调试：动态加载 vConsole ​

手机端不方便看控制台时，可以把 vconsole.min.js 上传到资源库，然后在页面系统初始化中动态导入。

javascript
async function main() {
  await SystemJS.import('/dfs/group1/M00/00/01/vconsole.min.js')
  new VConsole()
}

main()

注意：

  • 不建议生产环境长期打开。
  • 路径要换成你上传后的资源路径。

4.4 老安卓兼容性 ​

原文档特别提醒：部分老安卓不支持可选链 ?.。

不推荐：

javascript
const value = obj && obj.a && obj.a.b

上面这种虽然啰嗦，但兼容性更稳。也可以使用 utils.get：

javascript
const value = utils.get(obj, 'a.b.0.c', '')

说明：这里不是说不能写现代语法，而是移动端兼容场景下要保守。

5. 获取和设置变量 ​

5.1 获取变量值 ​

javascript
const list = getValueByName({
  name: 'VAR_craneList',
  type: 'var'
}) || []

5.2 设置变量值 ​

javascript
setValueByName({
  name: 'VAR_craneList',
  type: 'var',
  value: nextList
})

5.3 简写函数 ​

文档中也出现过：

javascript
setVar('VAR_craneList', nextList)

以及：

javascript
const value = getVariableValue('VAR_craneList')

项目里建议统一风格。为了便于读写组件和变量，本手册优先使用：

javascript
getValueByName({ name, type, attr })
setValueByName({ name, type, attr, value })

5.4 使用变量保存公共函数 ​

如果多个插件要共用函数，可以把函数挂到变量里。

初始化公共函数：

javascript
function formatDate(value) {
  return dayjs(value).format('YYYY-MM-DD')
}

function isEmpty(value) {
  return value === undefined || value === null || value === ''
}

setValueByName({
  name: 'VAR_commonFuncs',
  type: 'var',
  value: {
    formatDate: formatDate,
    isEmpty: isEmpty
  }
})

调用公共函数：

javascript
const commonFuncs = getValueByName({
  name: 'VAR_commonFuncs',
  type: 'var'
})

const text = commonFuncs.formatDate(new Date())
console.log(text)

建议：

  • 公共函数变量适合放在页面初始化逻辑中。
  • 不要把特别复杂的大段业务逻辑都塞进变量，后期不好维护。

8.5 弹窗中获取用户输入 ​

可以使用 MessageBox.alert 的 HTML 功能，但要注意 DOM 可能不会马上渲染完成。

javascript
function dialogPopup() {
  const htmlString =
    '<div>' +
    '<span>请输入备注：</span>' +
    '<input id="remarkInput">' +
    '</div>'

  MessageBox.alert(htmlString, '提示', {
    dangerouslyUseHTMLString: true
  }).then(function () {
    const remark = document.getElementById('remarkInput').value
    console.log('用户输入:', remark)
  })
}

dialogPopup()

如果要在弹窗打开后给 HTML 元素绑定事件，建议加短延迟：

javascript
setTimeout(function () {
  const input = document.getElementById('remarkInput')
  if (!input) return

  input.addEventListener('change', function (e) {
    console.log('输入变化:', e.target.value)
  })
}, 200)

11. 调用后端插件 ​

11.1 基础写法 ​

javascript
async function main() {
  const pluginId = 'ingin_替换为实际插件ID'

  const resp = await invokeBackPlugin(pluginId, {
    xplugin_func: 'run_test',
    xplugin_data: {
      name: '测试'
    }
  })

  console.log('后端插件返回:', resp)
}

main()

11.2 携带当前项调用后端插件 ​

javascript
async function main() {
  const pluginId = 'ingin_替换为实际插件ID'
  const currentItem = elem.repeater.childData

  if (!currentItem || !currentItem.id) {
    Toast.fail('未获取到当前项')
    return
  }

  const resp = await invokeBackPlugin(pluginId, {
    xplugin_func: 'handle_item',
    xplugin_data: {
      id: currentItem.id,
      item: currentItem
    }
  })

  console.log('处理结果:', resp)
}

main()

11.3 参数约定 ​

前端调用后端插件时建议统一使用：

javascript
{
  xplugin_func: '函数名',
  xplugin_data: {
    // 业务参数
  }
}

这样后端插件里能稳定按函数名分发逻辑。

13. 父子闪用页面通信 ​

13.1 子页面通知父页面 ​

子页面：

javascript
notifyParent({
  action: 'refresh',
  id: 'xxx'
})

父页面：

  • 注册触发器：系统 -> rcvWebappMsg
  • 在插件中读取 eventArgs
javascript
function main() {
  console.log('子页面消息:', eventArgs)

  if (eventArgs.action === 'refresh') {
    refreshCurrentData()
  }
}

main()

13.2 父页面给子页面传参数 ​

父页面设置闪用组件参数：

javascript
setValueByName({
  name: 'webapp_detail',
  type: 'elem',
  attr: 'attrs.attrs.params',
  value: {
    command: 'init',
    recordId: 'xxx_id'
  }
})

子页面：

  • 注册触发器：系统 -> rcvParams
  • 在插件中读取 eventArgs
javascript
function main() {
  console.log('父页面参数:', eventArgs)

  if (eventArgs.command === 'init') {
    initPage(eventArgs.recordId)
  }
}

main()

13.3 切换子页面时的推荐顺序 ​

如果父页面里有闪用组件，想切换它的页面并传参数，建议顺序：

  1. 先设置 attrs.attrs.params
  2. 再设置 attrs.attrs.ncConfigId
  3. 再打开弹框或显示组件
javascript
setValueByName({
  name: 'webapp_popup',
  type: 'elem',
  attr: 'attrs.attrs.params',
  value: {
    command: 'init',
    recordId: 'xxx_id'
  }
})

setValueByName({
  name: 'webapp_popup',
  type: 'elem',
  attr: 'attrs.attrs.ncConfigId',
  value: '目标闪用页面ID'
})

原因：子页面初始化顺序通常是 sysInit -> pageEnter -> rcvParams，如果参数设置晚了，子页面初始化可能拿不到。

13.4 子页面之间传参 ​

子页面之间可以用 storageApi：

javascript
await storageApi.setItem('selectedId', selectedId)

另一个子页面：

javascript
const selectedId = await storageApi.getItem('selectedId')

14. 闪用页面向闪搭页面传消息 ​

如果闪用页面嵌在闪搭页面里，可以用 window.parent.postMessage。

闪用页面：

javascript
const host = location.origin
const action = 'refresh'
const params = {}

window.parent.postMessage({
  action: action,
  params: params
}, host)

闪搭页面：

  • 插件场景：表格详情
  • 对象事件：页面消息
  • 通过 eventData 接收参数
javascript
console.log('eventData:', eventData)

if (eventData.action === 'refresh') {
  refreshTable()
}

注意：

  • postMessage 第二个参数建议使用明确的源，不要随便写 *。
  • 参数结构建议统一 { action, params }。

17. 动态修改样式 ​

17.1 直接修改 DOM 样式 ​

适合确实没有组件属性可配的场景。

javascript
let divElement = document.querySelector('div.ql-editor.ql-blank')
let maxAttempts = 10
let attempts = 1

function findDivElement() {
  if (!divElement && attempts <= maxAttempts) {
    setTimeout(function () {
      divElement = document.querySelector('div.ql-editor.ql-blank')
      attempts++
      findDivElement()
    }, 100)
  } else {
    if (divElement) {
      divElement.style.fontSize = '22px'
      divElement.style.lineHeight = '46px'
    } else {
      console.log('未找到元素')
    }
  }
}

findDivElement()

17.2 动态添加 CSS 类 ​

javascript
const styleSheet = document.createElement('style')
document.head.appendChild(styleSheet)

const sheet = document.styleSheets[document.styleSheets.length - 1]

function defineCSSClass(className, styles) {
  let rules = ''

  for (const property in styles) {
    if (styles.hasOwnProperty(property)) {
      rules += property + ':' + styles[property] + ';'
    }
  }

  sheet.insertRule('.' + className + '{' + rules + '}', sheet.cssRules.length)
}

defineCSSClass('noMinHeight', {
  'min-height': '0px !important'
})

setTimeout(function () {
  const list = document.getElementsByClassName('vxe-table--body-wrapper body--wrapper')

  for (let i = 0; i < list.length; i++) {
    list[i].classList.add('noMinHeight')
  }
}, 500)

建议：

  • 优先使用组件属性、变量绑定、样式配置。
  • DOM 查询和动态 CSS 作为兜底方案。
  • 需要考虑组件异步渲染，所以经常要延迟或重试。

18. 阻止事件冒泡 ​

多层元素都有点击事件时，内部按钮可能触发外层组件事件。

典型问题：

  • 点“编辑”按钮，同时触发卡片点击。
  • 点“删除”按钮，同时跳转详情页。

推荐做法：

  • 在按钮组件事件配置里开启阻止冒泡。
  • 这是平台支持的方式，比在代码里猜原生事件对象更稳。

如果事件参数里有原生事件对象，可以尝试：

javascript
if (eventArgs && eventArgs.event && eventArgs.event.stopPropagation) {
  eventArgs.event.stopPropagation()
}

19. 生命周期和触发器选择 ​

19.1 sysInit ​

页面配置加载后、页面组件加载前触发。

适合：

  • 定义全局共享函数
  • 设置轻量级全局变量

不适合：

  • 耗时请求
  • 大量异步初始化

原因：此时页面可能还是白屏，耗时操作会影响首屏加载。

19.2 pageEnter ​

页面组件加载同时触发。

适合：

  • 页面初始化数据
  • 调接口加载列表
  • 设置组件默认状态

19.3 rcvParams ​

闪用组件收到父页面参数时触发。

适合：

  • 嵌入式子页面初始化
  • 根据父页面传参加载数据
  • 弹框中子页面复位

闪用组件初始化顺序通常是：

text
sysInit -> pageEnter -> rcvParams

如果页面依赖父页面传参，优先把初始化逻辑放到 rcvParams。

20. 弹框中的闪用组件初始化建议 ​

20.1 弹框重新渲染模式 ​

特点：

  • 每次打开弹框，内部组件重新渲染。
  • 状态干净，不容易残留上一次数据。
  • 复杂组件加载会慢一点。

推荐流程：

  1. 设置弹框内部组件初始值。
  2. 设置闪用组件 attrs.attrs.params。
  3. 设置闪用组件 attrs.attrs.ncConfigId。
  4. 打开弹框。
  5. 子页面在 rcvParams 中初始化。

20.2 弹框非重新渲染模式 ​

特点：

  • 打开速度快。
  • 关闭后组件状态可能残留。

推荐流程：

  1. 打开前设置参数和初始值。
  2. 子页面在 rcvParams 中初始化。
  3. 关闭时主动清理变量或组件值。
  4. 下次打开前重新设置参数。

复位参数例子：

javascript
setValueByName({
  name: 'webapp_detail',
  type: 'elem',
  attr: 'attrs.attrs.params',
  value: {
    command: 'reset'
  }
})

子页面：

javascript
function main() {
  if (eventArgs.command === 'reset') {
    resetPage()
  }
}

main()

21. 常见坑 ​

21.1 eventArgs 里没有想要的数据 ​

原因：

  • 不同组件的事件参数结构不一样。
  • 绑定的事件不是你以为的那个事件。
  • 当前组件没有把行数据或当前项作为事件参数传出。

处理：

javascript
console.log('eventArgs:', eventArgs)
console.log('elem:', elem)

如果是迭代器或 List，优先看：

javascript
console.log(elem.repeater.childData)

21.2 getModel 拿不到字段 ​

原因通常是表单或字段没有配置程序标识。

处理：

  • 到表单编辑里检查程序标识。
  • 字段也要配置程序标识。
  • 重新保存配置后再测试。

21.3 设置组件属性无效 ​

排查：

  • 组件名称是否正确。
  • type 是否为 'elem'。
  • attr 路径是否正确，例如 attrs.attrs.value、styles.display。
  • 组件是否还没渲染完成。

21.4 设置变量后页面不更新 ​

排查：

  • 变量名是否正确。
  • type 是否为 'var'。
  • 迭代器或组件是否绑定了这个变量。
  • 是否直接改了原数组但没有 setValueByName 回写。

21.5 手机端插件报错但电脑端正常 ​

排查：

  • 是否使用了老安卓不支持的语法，例如可选链。
  • 是否依赖了浏览器特定 API。
  • 是否需要加载 vConsole 看手机端报错。

24. 推荐实践 ​

  1. 每个插件都写 main()，异步逻辑写 async main()。
  2. 新组件、新事件先打印 elem、event、eventArgs。
  3. 迭代器和 List 当前项优先用 elem.repeater.childData。
  4. 读写变量和组件属性优先统一使用 getValueByName / setValueByName。
  5. 依赖父页面传参的子页面，初始化逻辑优先放在 rcvParams。
  6. 页面跳转临时传参用 storageApi。
  7. 父子闪用页面通信用 notifyParent、rcvWebappMsg、attrs.attrs.params、rcvParams。
  8. 移动端页面避免使用兼容性差的语法，尤其是老安卓环境。
  9. 动态 DOM 和 CSS 修改作为兜底方案，优先使用组件属性和变量绑定。
  10. 复杂弹框如果关闭后要保留性能，记得自己写复位逻辑。
